# BGM 8곡 — 여기에 넣습니다

파일명은 **`{id}.mp3`** 입니다. `id` 는 `.vns` 의 `@bgm` 에 그대로 쓰는 값이라, 다른 이름으로 넣으면 스크립트 105씬을 다 고쳐야 합니다.

정본은 [WORLD_BIBLE 10-1](../../../docs/WORLD_BIBLE.md#10-1-bgm-8곡)이고, 아래 `쓰이는 곳` 은 [`src/script/`](../../../src/script) 를 실제로 훑어 센 것입니다.

---

## 여덟 곡

| `id` | 톤 | 쓰이는 곳 | 횟수 |
|---|---|---|---|
| `title` | 여름 · 기대 · 약간의 쓸쓸함 | 타이틀 화면 — 스크립트 밖에서 UI 가 켭니다 | — |
| `day` | 밝고 가벼운 루프 | 입소 첫날 · 조 배정 · 얼굴 익히기 · **D7 외출 세 곳(낮)** | 22 |
| `session` | 리듬감, 존재감 낮게 | 오리엔테이션 · 짝 프로그래밍 | 7 |
| `night` | 잔잔한 로파이 | 자율 개발 밤 · 자유 이동 · 귀소 시내버스 | 4 |
| **`midnight`** | **이 게임의 메인 테마. 피아노 중심** | 커넥트가든 새벽 두 시 · D9 심야 교육장 403 | 12 |
| `tension` | 긴장 · 갈등 | 랭킹 공개 · 첫 좌절 · 조 충돌 밤샘 | 13 |
| `swell` | 감정 고조 | **고백** · D12 수료식 | 7 |
| **`epilogue`** | **`midnight` 의 편곡 버전** | 5년 후 — 엔딩 19종 전부 | 19 |

**여덟 개가 전부입니다.** `@bgm` 에 이 목록 밖의 값이 나오면 곡이 하나 늘어난 것이므로 `WORLD_BIBLE 10-1` 부터 고칩니다. `tools/check_vns.py` 가 그걸 검사합니다.

## 고를 때 놓치면 안 되는 셋

### `midnight` 과 `epilogue` 는 같은 멜로디여야 합니다

서로 다른 두 곡이 아니라 **한 곡의 두 벌**입니다. 열이틀 내내 새벽 두 시에 흐르던 곡이 5년 뒤 에필로그에서 편곡으로 돌아오는 것이 [WORLD_BIBLE 10-1](../../../docs/WORLD_BIBLE.md#10-1-bgm-8곡)이 말하는 **"이 게임의 마지막 한 방"** 입니다.

**이 둘만 맞으면 나머지는 무난해도 됩니다.** 반대로 이 둘이 남남이면 다른 여섯 곡이 좋아도 마지막이 안 살아납니다.

### 여명 전용 곡은 만들지 마세요

D7 커넥트가든에서 해가 뜨는 씬은 **`midnight` 을 그대로 쓰되 편성만 얇게** 갑니다. 게임에서 유일하게 해가 뜨는 장면이라, 새 곡보다 같은 멜로디가 밝아지는 쪽이 강합니다.

그래서 `midnight` 은 실질적으로 **세 벌**이 될 수 있습니다 — 원본 · 얇은 여명 버전 · `epilogue` 편곡.

### `night` 는 횟수가 적지만 짧게 만들면 안 됩니다

4회뿐이지만 **자유 이동 구간에서 도트 맵을 걸어 다니는 내내** 깔립니다. 실제 재생 시간은 호출 횟수와 무관하게 깁니다.

반대로 `session`(7회)은 강의 씬이라 존재감이 낮아야 하고 금방 지나갑니다. **횟수로 곡 길이를 정하지 마세요.**

## 규격

| | |
|---|---|
| 경로 | `public/audio/bgm/{id}.mp3` — 바로 이 폴더 |
| 형식 | **MP3 또는 OGG.** 웹이라 무손실이 필요 없습니다 |
| 길이 | **자연스럽게 도는 루프.** 60~120초면 충분합니다 |
| 이름 | 위 표의 `id` 그대로 — `midnight.mp3` `epilogue.mp3` … |

`public/` 은 Vite 가 그대로 복사하므로 별도 설정이 필요 없습니다 ([TECH_DESIGN 2절](../../../docs/TECH_DESIGN.md#2-프로젝트-구조)).
