# assets — 에셋 규격

**폴더가 맥락을 줍니다.** 그래서 파일명에 접두어를 붙이지 않습니다.

이름은 VN 관례를 따릅니다 — **立ち絵**(대화 중 서 있는 반신)와 **イベントCG**(명장면 한 장)는 그리는 방식도 쓰이는 자리도 달라서 원래 별개로 부릅니다. **ドット絵**는 픽셀 아트고, `SD`는 등신 비율을 가리키는 말이라 이 자리엔 안 맞습니다.

```
assets/
├─ cg/
│    standing/      {id}_{campus|outing}_{expr}.png    72   立ち絵
│    event/         {id}_{garden|classroom|ending}.png 18   イベントCG
├─ dot/
│    walk/          {id}.png                           18   192×256 시트
│    face/          {id}_{expr}.png                    36   48×64 감정 아바타
├─ bg/
│    outing/        4    D7 캠퍼스 밖
│    epilogue/      4    5년 후
│    campus/indoor/ 12 · outdoor/ 5    캠퍼스 사진
├─ map/             7    Tiled json
├─ tilesets/        11   png + tsj + index
└─ ui/              4    logo · intro ×3
```

**인물이 어떻게 생겼는지는 [`CHARACTERS.md`](../docs/CHARACTERS.md)가 정본입니다.** 여기는 규격만 다룹니다.

## CG

| | |
|---|---|
| **반신** 캔버스 | **1024 × 1280px 세로(4:5) · 투명 배경 PNG** |
| 크롭 | **가슴 위 반신.** 전신이 아니라 흉상입니다 — 얼굴이 크게 보여야 표정 6종이 일을 합니다 |
| 인물 배치 | 캔버스 가로 중앙, 머리 위에 여백 5~8% |
| **스틸** 캔버스 | **가로 16:9 · 불투명.** 배경까지 한 장에 그립니다 |

> **제약은 비율이지 해상도가 아닙니다.** 스틸 18장은 생성 도구 출력 그대로 **1672 × 941**(1.777)이고, 게임이 화면에 맞춰 늘립니다. 1920 × 1080으로 다시 뽑으면 더 선명해지지만 지금도 표시에는 충분합니다.

**표정을 바꿀 때 크로스페이드 120~150ms.** 몸통과 표정을 나눠 얹지 않고 한 장으로 그려서 장마다 어깨 위치가 미세하게 다릅니다. 하드 컷이면 인물이 튑니다.

**대신 표정마다 몸이 따라갑니다** — 화남엔 팔짱을 끼고 부끄럼엔 손이 올라옵니다. 나눴다면 팔짱 낀 몸통에 기쁨이 안 얹혔을 겁니다.

**명찰은 `campus`만 착용하고 `outing`은 없습니다.** 벗는 건 D7 외출과 D12 수료식 두 번뿐이라 **없어질 때만 눈에 띄는 물건**입니다 ([WORLD_BIBLE 7-3](../docs/WORLD_BIBLE.md#7-3-공통--참가자-명찰)).

## 도트

| | |
|---|---|
| **셀** | **48 × 64px** |
| **시트** | 4열 × 4행 = **192 × 256px** |
| 인물 높이 | **56 ~ 62px** (2~2.5등신) · 발은 셀 하단에서 **2px 위** |
| 배경 | 투명 (알파 0) |
| 색 수 | **3,900 ~ 14,200색** · 외곽선 어두운 색 1px |
| 명찰 | 가슴에 밝은 **2 × 3px 사각형** + 목에서 내려오는 1px 검은 줄. **전 컷 착용** |

**폭은 타일 한 칸(48px)이고 세로만 1.33칸입니다.** 정사각에 2.5등신을 넣으면 긴 머리가 들어갈 자리가 없습니다 — 민아·윤정은 높게 묶은 머리, 승희는 허리까지 오는 웨이브입니다.

### 도트는 진짜 픽셀 아트가 아닙니다

**픽셀처럼 보이게 그린 안티에일리어싱 일러스트**입니다. 2×2 블록이 단색인 비율이 41~60%뿐이고(진짜 픽셀 아트라면 논리 픽셀 크기에서 100%), 색이 인물당 수천 개입니다.

**그래서 렌더 필터가 타일과 달라야 합니다.**

| | 필터 | 왜 |
|---|---|---|
| 타일셋 | **NEAREST** | 코드로 그린 진짜 픽셀 아트. 27~32색 팔레트 스냅 |
| **도트 · 감정 아바타** | **LINEAR** | 안티에일리어싱이 이미 들어 있어서, NEAREST로 확대하면 그 흐린 픽셀이 각져서 지저분해집니다 |

전역은 `pixelArt: true`로 두고 도트 텍스처만 따로 겁니다.

```ts
this.textures.get('dot_minah').setFilter(Phaser.Textures.FilterMode.LINEAR);
```

**M1 위에 얹어 확인했습니다.** 타일이 20색 저채도라 인물이 눈에 먼저 들어오는데, 배경이 조용하고 캐릭터가 도드라지는 건 VN·RPG에서 정상입니다. 붕 뜨지 않습니다.

### 시트 배치

| | 1열 | 2열 | 3열 | 4열 |
|---|---|---|---|---|
| **1행** | **아래** 정지 | 걷기1 | 걷기2 | 걷기3 |
| **2행** | 왼쪽 | | | |
| **3행** | 오른쪽 | | | |
| **4행** | 위 | | | |

걷기는 **`2 → 3 → 4` 순환**, 멈추면 1열. 3열이 두 발 모인 중간 자세라 그것만으로 자연스럽게 돕니다. **왼쪽 행은 오른쪽 행의 좌우 반전**이라 두 방향이 어긋날 수 없습니다.

### 맵 위 배치

타일이 48 × 48px입니다. 타일 `(x, y)`에 서 있을 때 **`(x*48, y*48 − 16)`** 에 그립니다 — 머리가 위 칸을 16px 침범합니다.

> **타일 쪽 색 수가 27~32색입니다.** 인물이 8~12색이면 배경보다 단순해서 눈에 먼저 들어옵니다. 의도된 차이입니다.

### 공용 3종 — 무명 동기 17명용

**한 종을 색만 바꿔 대여섯 번 재활용**합니다.

| | 실루엣 | 갈아 끼우는 것 |
|---|---|---|
| `mob_a` | 반팔 티 + 반바지 | **티셔츠 색만** |
| `mob_b` | 후드집업 + 긴 팬츠 | **후드 색만** |
| `mob_c` | 셔츠 + 청바지 | **셔츠 색만** |

**얼굴 디테일을 넣지 마세요** — 배경 인원이라 눈에 띄면 안 됩니다. 교체용 색은 이름 있는 인물이 쓰지 않는 **회갈 · 연보라 · 올리브 · 남색 · 벽돌**에서 고릅니다.

**해상도는 제각각이고 그래도 됩니다.** 화면이 1920 × 1080이고 전 배경에 `object-fit: cover`를 걸어 채웁니다 — 세로가 남는 사진은 위아래가 잘립니다. 잘린 뒤 1920까지 확대되는 배율이 **1.00 ~ 1.25배**라 원본을 자르거나 키워 둘 이유가 없습니다.

### 배경 보정

**아홉 장 전부 회화풍으로 보정합니다.** 촬영본이든 생성본이든 **현재 배경은 전부 실사풍**이고, 웹툰풍 그림 옆에 그대로 두면 화풍이 튑니다.

| 겹 | 거는 대상 | 값 |
|---|---|---|
| **1 · 회화풍** | **배경 9장 전부** | `saturate(.62) contrast(.90) brightness(.97) blur(3px)` |
| **2 · 색조** | 낮 사진 4장 | `#FFE6B8` **soft-light 12%** |
| | `bus_night` | `#153A4A` **multiply 20%** |
| | 에필로그 4장 | **없음** — 시간대 시스템 밖 |
| **3 · 스프라이트** | **`bus_night` 씬의 반신 CG** | `#153A4A` **multiply 22%** |

**채도는 1겹에서 한 번만 겁니다.** [`lighting.ts`](../src/config/lighting.ts)의 `day`에 `saturation: −0.1`이 붙어 있지만 그건 타일맵용입니다. 사진에 또 걸면 이중으로 빠집니다.

```css
.vn-bg        { width:100%; height:100%; object-fit:cover; }
.vn-bg--paint { filter: saturate(.62) contrast(.90) brightness(.97) blur(3px); }
```

`blur(3px)`은 1920 폭의 0.16%입니다. **실사의 픽셀 단위 선명함을 깎는 것이 목적**이고, 반신 CG가 서는 씬에서는 배경이 한 걸음 물러나는 효과도 같이 얻습니다.

#### 에필로그는 색조를 걸지 않습니다

**시간대 팔레트는 캠프 열이틀의 장치**입니다([WORLD_BIBLE 8-1](../docs/WORLD_BIBLE.md#8-1-시간대별-팔레트)). 5년 후는 그 계통 밖이라 색조를 얹지 않고 회화풍만 겁니다.

**그래도 회화풍은 걸어야 합니다.** 에필로그 씬은 **엔딩 스틸과 번갈아 나오는데**, 스틸은 얕은 심도까지 들어간 회화풍입니다. 배경만 전면 선명하면 컷이 바뀔 때마다 화풍이 튑니다.

#### 밤 사진은 색조를 절반만 겁니다

[`lighting.ts`](../src/config/lighting.ts)의 `night`는 **multiply 45%**인데 `bus_night`에는 **20%**를 겁니다. 값이 갈리는 게 아니라 **바탕이 다릅니다** — 타일맵은 한낮 밝기로 그려 놓고 밤으로 옮기지만, `bus_night`은 **이미 밤에 찍은 사진**이라 어둠이 들어 있습니다. 45%를 걸면 평균 밝기가 38 → 24로 내려가 하차벨과 창밖 가로등이 죽습니다. 20%면 31입니다.

**낮 사진 넷은 12%를 그대로 씁니다.** soft-light라 밝기가 거의 안 변합니다(131 → 130).

#### 스프라이트에도 걸어야 합니다

**반신 CG는 전부 중립 조명으로 그려져 있습니다.** 밤 배경 위에 그대로 얹으면 인물만 대낮이라 붙여넣은 것처럼 보입니다. 배경과 **같은 색을 절반 세기로** 걸면 같은 조명 아래로 들어옵니다.

**낮 씬과 에필로그에는 걸지 않습니다** — soft-light 12%의 절반은 눈에 보이지 않고, 에필로그에는 반신 CG가 서지 않습니다(엔딩 스틸이 인물을 품습니다).

## UI

**화면 넷 중 새로 그릴 그림은 로그인 배경 하나뿐**입니다. 대사창·방명록·타이틀 레이아웃은 HTML/CSS라 에셋이 아닙니다. 톤과 배치는 [WORLD_BIBLE 11절](../docs/WORLD_BIBLE.md#11-ui-톤)이 정본입니다.

| 파일 | |
|---|---|
| `intro_blank.png` | 프레임만 — 금빛 장식 네 귀 · 1920×1080 |
| `intro_small.png` | 로고 작게 · 1920×1080 |
| `intro_large.png` | 로고 크게 · 1920×1080 |
| `logo.png` | 로고 단독 · 1254×1254 |

> **`logo.png`는 배경이 구워져 있습니다** — 완전 불투명이고 모서리가 `#0B0B17`입니다. `intro_blank`는 `#0A0A15`라 **1~2 어긋나서**, 위에 얹으면 사각형 경계가 보입니다. 다른 화면에 재활용하려면 투명 버전이 따로 필요합니다.

### 로그인 배경 — 아직 없습니다

타이틀 **앞**에 오는 화면입니다. 게스트 플레이가 없어 여기를 지나야 게임이 시작됩니다 ([GAME_DESIGN 2-5](../docs/GAME_DESIGN.md#2-5-계정과-방명록)). 구현 시안은 [`login.html`](../docs/reference/ui/login.html)에 있습니다.

배경은 **낮의 커넥트가든** — 아직 아무 일도 없었던 시간대입니다.

```
minimal login screen for a visual novel game, full-bleed background photo of a
sunlit outdoor wooden deck garden, heavy dark overlay for text legibility,
centered single button labeled "Google로 계속하기", one short line of caption text
below it, generous whitespace, no other ui elements, 16:9
```

## 용량

**전부 PNG라 `assets/`가 187MB입니다.**

| | |
|---|---|
| `cg/` 90장 | **119MB** — 반신 71 · 스틸 48 |
| `bg/campus/` 17장 | 41MB |
| `bg/` 나머지 9장 | 21MB |

웹 배포 전에 **WebP 변환이 필요합니다** — CG는 q90이면 ~11MB로 내려갑니다. **도트는 무손실이어야 하므로 PNG를 유지합니다.**
