# jungLover

### 11박 12일, 연애는 커리큘럼에 없었다

부트캠프를 무대로 한 **연애 시뮬레이션 웹 게임**

</div>

---

크래프톤 정글 캠퍼스에서 보내는 열이틀. 잠은 모자라고 과제는 끝나지 않는데, 하필 그 안에서 사람이 눈에 들어옵니다.

**여섯 인물, 각자의 루트, 열아홉 가지 결말.** 호감도 게이지는 화면에 없습니다. 관계가 어디까지 왔는지는 **상대가 나를 부르는 호칭**과 대사의 온도로만 드러납니다.

## 이런 게임입니다

| | |
|---|---|
| **분량** | 105씬 · 2,115줄 · 1회차 20~30분 |
| **루트** | 히로인 6인 — 각자 독립. 묶음 라벨 없이 여섯이 다 다릅니다 |
| **결말** | 6인 × 3티어 + 솔로 = **19종** |
| **무대** | 실제 캠퍼스 도면과 사진을 도트 타일맵 7개로 옮겼습니다 |
| **특징** | 캠퍼스 **안에서는 도트 맵을 걸어 다니고**, 밖으로 나가면 한 장 배경의 이벤트 씬으로 바뀝니다 |

**감정의 정점은 새벽 두 시**입니다. 주변에 도시 불빛이 없는 캠퍼스라 그 시간의 어둠이 진짜 어둠이 되고, 조명 오버레이 다섯 종 가운데 심야가 가장 진합니다.

## 기술

| | |
|---|---|
| 프론트 | **TypeScript · Vite** |
| 맵 | **Phaser 3** — 도트 타일맵 · 충돌 · 맵 전환 |
| VN 레이어 | **순수 DOM/CSS** — 대사창·선택지·CG는 캔버스 밖 |
| 대사 | 자체 **`.vns` DSL** → 빌드 시 JSON으로 컴파일 |
| 계정·저장 | **Firebase** Auth + Firestore. 서버 측 로직은 `firestore.rules` |
| 배포 | GitHub Pages |

**직접 운영하는 서버 애플리케이션은 없습니다.** 백엔드는 Google 관리형이고, 접근 제어를 규칙 언어로 서술해 올립니다.
