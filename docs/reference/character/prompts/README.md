## 순서

[17절](../ART_BRIEF.md#17-생성-도구로-만들-때의-순서)대로입니다. **처음 셋이 갈림길입니다.**

```
① B01  김민아 평상복 몸통      ← 여러 번 뽑아 하나 확정
② F01  김민아 표정 시트        ← 잘라서 ①에 얹어봅니다
③ S01  김민아 도트 시트        ← 48px로 줄여 pixel_demo.png와 비교
   ─────────────────────────  여기까지 통과해야 나머지가 의미 있습니다
④ B02        김민아 외출복
⑤ B03~B12    나머지 5인 몸통 10장
⑥ F02~F06    나머지 5인 표정 시트
⑦ S02~S06    나머지 5인 도트
⑧ S07~S18    참조 없는 12종 도트   ← 외형 확정 후
⑨ T01~T18    스틸 18장            ← 가든부터
```

> **②와 ③이 이 프로젝트의 갈림길입니다.** 둘 다 되면 54번으로 끝나고, 표정 시트가 안 되면 얼굴을 인페인팅해야 해서 **36번이 더 붙습니다**(총 90번).

**참조 이미지가 어떻게 물리는지**가 순서의 이유입니다.

```
refs/ref_{id}.png ─┬─→ 평상복 몸통 ─┬─→ 외출복 몸통
                   │                ├─→ 표정 시트
                   │                └─→ 스틸 ①②③
                   └─→ 도트 시트(히로인) ─→ 도트 12종
```

`refs/` 크롭이 직접 들어가는 건 **평상복 몸통 6장과 히로인 도트 6장뿐**입니다. 나머지 42건은 전부 *확정된 결과물*을 물립니다 — 그래야 얼굴이 한 번만 정해지고 끝까지 유지됩니다.

## 스타일 접미사를 카테고리별로 쪼갠 이유

[10절](../ART_BRIEF.md#10-공통-프롬프트-조각)은 스타일 접미사를 **"모든 인물 프롬프트 뒤에 붙입니다"**라고 했습니다. **그대로 따르면 4개 중 3개 카테고리가 망가집니다.** 접미사 안에 화풍과 구도가 섞여 있기 때문입니다.

```text
korean webtoon illustration style, semi-realistic anime, soft cel shading,   ← 화풍
clean lineart, warm muted palette,                                           ← 화풍
hair rendered in exactly the stated color, ...                               ← 화풍
tight bust portrait, head and shoulders shot, cropped at the sternum,        ← 구도
the bottom edge of the frame sits just below the collarbone, ...             ← 구도
subject centered horizontally ... a small empty gap above the head, ...      ← 구도
relaxed neutral posture, arms lowered naturally, calm neutral expression,    ← 구도
flat solid chroma key green background, one uniform color, no gradient       ← 구도
```

| 카테고리 | 화풍 | 구도 | 이유 |
|---|:---:|:---:|---|
| **몸통** | ✅ | ✅ | 10절 원문 그대로입니다 |
| **표정 시트** | ✅ | ❌ | 12절은 "**얼굴과 목까지만.** 몸통·손은 넣지 마세요" — `bust crop`과 충돌 |
| **도트 시트** | ❌ | ❌ | 웹툰 화풍을 붙이면 픽셀이 깨집니다. 14절은 "**의상·머리 부분만** 가져다 붙입니다" |
| **스틸** | ✅ | ❌ | 배경을 그려야 하는데 `chroma key green background`가 막습니다. 감정이 목적인데 `calm neutral expression`이 막습니다 |

부정 프롬프트도 같은 이유로 나눴습니다.

- **표정 시트** — `strong emotion, laughing, crying, angry face`를 **뺐습니다.** 이 시트가 만들어야 하는 게 바로 그 표정입니다. 12절 지시대로 10절 부정에 그냥 더하면 시트가 자기 목적을 부정합니다
- **스틸 ①②** — `cropped head, full body, legs, feet, busy background`와 포즈·감정 차단 토큰(`dramatic pose, arms crossed, raised hands, hands near the face, strong emotion, laughing, crying, angry face`)을 **전부 뺐습니다.** 배경과 전신이 나오고, 감정이 이 컷의 목적입니다 — 승민 ①은 아예 "울던 걸 들킨 직후"입니다. 대신 [16절 후처리 체크리스트](../ART_BRIEF.md#16-생성-결과-후처리-체크리스트)를 부정 프롬프트로 옮겼습니다 — `city lights, bright daylight, orange sunrise`
- **스틸 ②(클라이맥스)만** — `multiple characters, crowd`도 뺐습니다. 승희는 "조가 자기를 빼놓고 결정", 민규는 "아무도 눈치 못 챔" — **조원이 화면에 있어야** 성립하는 컷입니다. ①가든은 1:1이라 그대로 둡니다
- **스틸 ③(엔딩)** — ①②의 어둠 토큰을 **쓰지 않습니다.** 엔딩은 낮·실내라 `bright daylight`를 부정하면 `late afternoon light`와 정면 충돌합니다

## 자르기

시트를 손으로 자르지 마세요. [`tools/cut_sheet.py`](../../../../tools/cut_sheet.py)가 격자로 잘라 이름까지 붙입니다. **각 시트 파일에 실행할 명령줄이 그대로 적혀 있습니다.**

주의할 점 둘:

- **`--trim`과 `--resize`를 같이 쓰지 마세요.** 스크립트는 `dekey → trim → resize` 순으로 도는데, 셀마다 잘리는 크기가 달라진 뒤 전부 48×48로 맞춰지면 **셀마다 배율이 달라져 걷기 애니메이션이 떨립니다.** 도트는 `--resize`만, 표정은 `--trim`만 쓰세요 (15절 예시가 이미 그렇게 나뉘어 있습니다)
- **표정 시트의 `--trim`은 셀 공통 좌표를 버립니다.** 6장이 각자 자기 여백만큼 잘려 나오므로 잘라낸 직후에는 위치가 안 맞습니다. 이게 12절의 "**눈동자 중심 두 점을 맞추고 나머지 5컷을 평행 이동**" 단계가 필요한 이유입니다 — 버그가 아니라 순서입니다
- **`--resize 48x48`은 최근접 이웃 축소입니다.** 원본이 이미 격자에 맞는 선명한 픽셀아트일 때만 깨끗합니다. 생성 결과가 안티에일리어싱된 상태면 256px→48px(5.33배) 축소에서 외곽선이 지저분해집니다. [16절 체크리스트](../ART_BRIEF.md#16-생성-결과-후처리-체크리스트)의 *"안티에일리어싱이 섞이면 원본을 다시"*가 이 얘기입니다
