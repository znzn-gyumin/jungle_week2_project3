**스틸 CG 18장**을 위한 것입니다. 파일 하나가 요청 하나이고, 열면 **첨부할 것 · 프롬프트 · 부정 · 검수 항목**이 다 들어 있습니다.

| 폴더 | 내용 | 개수 |
|---|---|---|
| `04_still/` | `T01`~`T06` 가든 · `T07`~`T12` 클라이맥스 · `T13`~`T18` 엔딩 | **18** |

**프롬프트는 한글입니다.** 넣는 사람이 한국어로 판단해야 「여명이 보라→파랑인가」 같은 검수가 성립합니다. 프롬프트와 체크리스트가 다른 언어면 대조가 안 됩니다.

**여기 없는 나머지 둘은 방식이 달라서 없습니다.**

## 부정 프롬프트는 반드시 끊어서 넣으세요

각 파일의 프롬프트 블록에 `── 아래는 절대 넣지 마세요 ──` 구분선이 있습니다.

**도구에 부정 프롬프트 칸이 따로 있으면 구분선 아래를 거기에 옮기세요.** 없으면 구분선을 그대로 둔 채 넣으세요. **구분 없이 이어붙이면 `도시 불빛, 가로등, 네온사인, 주황빛 일출`이 그려달라는 지시로 읽힙니다** — 정확히 피하려던 것이 나옵니다.

## 인물 참조는 반신 CG입니다

**`refs/ref_*.png`를 쓰지 마세요.** 정본 얼굴은 이미 만든 **반신 CG**입니다.

| | 이유 |
|---|---|
| 얼굴이 갈립니다 | 원본 크롭을 넣으면 **대화 중 CG와 명장면 스틸이 다른 사람**이 됩니다 |
| 비율이 끌려갑니다 | `ref_*.png`는 **세로(0.729)**입니다. 출력이 첨부 참조의 가로세로비를 따라가므로 **가로 스틸에 넣으면 세로로 나옵니다** |

스틸은 **1920 × 1080 가로(1.778)**입니다.

## 순서

**스틸은 반신 CG가 확정된 뒤에 뽑습니다.** 얼굴이 먼저 고정돼야 열여덟 장이 같은 사람이 됩니다.

```
반신 CG 확정 ──→ T01~T06  가든        ← 여기부터
                 T07~T12  클라이맥스
                 T13~T18  엔딩
```

**가든이 가장 중요합니다.** 루트 최대 명장면이고 게임에서 유일하게 해가 뜨는 컷이라, 여기가 비면 정점이 없습니다. 나머지 둘은 없으면 대화 CG로 버티지만 가든은 안 됩니다.

## 부정 프롬프트가 씬마다 다른 이유

| | 뺀 것 | 왜 |
|---|---|---|
| **② 클라이맥스** | `여러 명, 군중` | 승희는 "조가 자기를 빼놓고 결정", 민규는 "아무도 눈치 못 챔" — **조원이 화면에 있어야** 성립합니다. ①가든은 1:1이라 그대로 둡니다 |
| **③ 엔딩** | 어둠 관련 전부 | 낮·실내라 `밝은 대낮`을 부정하면 `늦은 오후의 빛`과 정면 충돌합니다 |

**엔딩에서 랜야드를 통짜로 막으면 안 됩니다.** 차단 대상은 **캠프 명찰**(`검은 캠프 명찰, J 로고 뱃지, 학생증`)이지 사원증이 아닙니다 — 민아는 **사원증 랜야드**를 걸고, 윤호는 **강아지 뱃지가 사원증 스트랩에** 달립니다.
