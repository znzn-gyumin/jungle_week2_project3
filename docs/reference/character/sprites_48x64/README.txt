   밝은 테두리 픽셀을 안쪽 색으로 치환해 흰 테두리를 제거했습니다.
 - 알파를 이진화해 도트처럼 가장자리가 딱 떨어지도록 했습니다.
 - 걷기 스프라이트는 시트 전체가 같은 배율이며, 캐릭터별로 발밑 기준선이
   고정돼 있어 프레임을 넘겨도 위아래로 흔들리지 않습니다.
 - 감정 컷은 얼굴이 프레임을 채우도록 키우고, 반짝이/하트/눈물/화남 표시 등
   이펙트 요소를 각 파일 안에 함께 배치했습니다.
