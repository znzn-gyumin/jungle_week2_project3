서브 캐릭터 스프라이트 48x64 분할본
====================================
원본: sub_charactor_dot_1.png / _2.png / _3.png (각 1536x1024)
시트당 캐릭터 4명(2x2 배치) x 4방향 x 4프레임 = 64개, 3장 합쳐 192개.

폴더 구조
  sheet1|sheet2|sheet3 /
    48x64/   ... 실제 게임용 (48x64 px, 투명 PNG)
    192x256/ ... 동일 이미지의 4배 확대본 (nearest, 확인/미리보기용)
      <캐릭터>/<캐릭터>_<방향>_<모션>.png

방향: down(정면) / left / right / up(뒷면)   ※ 시트의 열 순서 그대로
모션: idle / walk1 / walk2 / walk3 = 걷기 애니메이션 4컷 (시트의 행 순서 그대로)

캐릭터 (시트 내 위치: 좌상 → 우상 → 좌하 → 우하)
  sheet1: hoodie_boy / hoodie_girl / redtee_boy / redtee_girl
  sheet2: uniform_boy / uniform_girl / hooded_figure / suit_man
  sheet3: apron_girl / whitetee_boy / hoodie_girl2 / blueshirt_boy

처리 내용
 - 흰 테두리 제거: 원본은 흰 외곽선을 알파 180(반투명 흰색)으로 칠해 두었는데,
   흰 티셔츠/조리모/흰 신발 같은 '진짜 흰 옷'도 같은 알파 180이었습니다.
   그래서 알파를 일괄로 자르지 않고, 바깥 배경에 닿아 있는 반투명 픽셀만
   2겹 벗겨냈습니다. 남아 있는 불투명 밝은 테두리는 안쪽 색으로 치환했습니다.
 - 알파를 이진화해 도트처럼 가장자리가 딱 떨어지게 했습니다.
 - 192개 전부 같은 배율(0.5586)이며, 캐릭터별로 발밑 기준선이 고정되어 있어
   프레임을 넘겨도 위아래로 흔들리지 않습니다.
 - 원본에 섞여 있던 머리 위 부유 점/막대 아티팩트는 제거했습니다.

알아두실 점
 - 이 시트에는 반짝이/하트 같은 이펙트 요소가 없습니다(감정 컷이 없는 걷기 전용 시트).
 - 원본에서는 3번째 열(right)의 그림이 2번째 열(left)과 같은 방향(왼쪽)을 보고 있었습니다.
   12명 전원의 right 4컷(총 48장)을 좌우 반전해 실제로 오른쪽을 보도록 맞춰 두었습니다.
   반전 시 각 스프라이트의 가로 중심을 그대로 유지해 애니메이션 좌우 떨림은 없습니다.
