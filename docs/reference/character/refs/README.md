# 인물별 레퍼런스 크롭 6장

[`ART_BRIEF.md` 9절 ②](../ART_BRIEF.md#9-프롬프트-쓰는-법)가 **필수**로 지정한 선행 산출물입니다.

> ② **참조 이미지 필수** — 프로필에서 **해당 인물만 잘라** character reference로 넣습니다. 안 넣으면 같은 인물이 매번 달라집니다

프로필 시트 2장을 그대로 물리면 모델이 **세 인물을 섞습니다.** 한 장에 한 사람만 있어야 합니다.

## 파일

원본은 둘 다 `1536 × 1024`입니다.

| 파일 | 인물 | 원본 | crop box (x0,y0,x1,y1) | 크기 |
|---|---|---|---|---|
| `ref_minah.png` | 김민아 | `heroine_girl_profile.png` | 4, 4, 506, 693 | 502 × 689 |
| `ref_seunghee.png` | 이승희 | `heroine_girl_profile.png` | 522, 4, 1015, 693 | 493 × 689 |
| `ref_yunjung.png` | 장윤정 | `heroine_girl_profile.png` | 1030, 4, 1532, 693 | 502 × 689 |
| `ref_mingyu.png` | 김민규 | `heroine_boy_profile.png` | 4, 4, 507, 693 | 503 × 689 |
| `ref_seungmin.png` | 이승민 | `heroine_boy_profile.png` | 524, 4, 1013, 693 | 489 × 689 |
| `ref_yunho.png` | 장윤호 | `heroine_boy_profile.png` | 1030, 4, 1532, 693 | 502 × 689 |

하단 이름표 카드는 **잘라냈습니다** — 카드 안의 한글 텍스트가 레퍼런스에 남으면 생성물에 글자가 딸려 나옵니다.

## 자른 기준

- **세로 경계** — 패널 사이 흰 여백 열을 밝기로 검출 (여자 `510–517` `1019–1025`, 남자 `511–519` `1017–1025`)
- **가로 경계** — 이름표 카드 상단이 여섯 패널 모두 `y=703`. 김민아 카드의 청록 탭이 `y=695`부터 위로 삐져나와 있어 **`y=693`에서 끊었습니다**
- 잔여 테두리를 없애려고 사방 4px씩 더 들어갔습니다
- 여섯 장 다 하단에 **명찰(J 카드)이 온전히 들어가도록** 맞췄습니다

## 주의

- 크롭에는 **책상·모니터·화이트보드 배경이 그대로 남아 있습니다.** 생성 시 [10절 부정 프롬프트](../ART_BRIEF.md#부정-프롬프트--공통)의 `busy background`가 이걸 막아줍니다. 배경까지 따라오면 크롭을 더 좁히지 말고 부정 프롬프트를 강화하세요 — 인물을 좁히면 헤어 실루엣 정보가 같이 날아갑니다
- **원본 포즈가 중립이 아닙니다** (민아 팔짱, 승희 손 모음, 윤정 주먹, 승민 활짝 웃음). [11절](../ART_BRIEF.md#11-몸통-프롬프트--12장)이 요구하는 건 중립 자세·중립 표정이므로, 이 크롭에서 가져올 것은 **얼굴·머리·의상뿐**입니다. 포즈와 표정은 따라오면 안 됩니다
- 여섯 다 **명찰(J 카드)이 보입니다.** 외출복 6장을 뽑을 때 부정 프롬프트에 `lanyard, id card, name tag, badge on chest`를 넣지 않으면 명찰이 따라옵니다
