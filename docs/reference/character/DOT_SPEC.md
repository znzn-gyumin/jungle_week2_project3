> **이 문서만 보고 그릴 수 있게 쓴 것입니다.** 다른 기획 문서를 안 읽어도 됩니다.
>
> **화풍은 그리는 사람이 정합니다.** 이 문서가 정하는 건 **규격·구성·외형**뿐입니다. 선 굵기, 음영 방식, 얼굴 표현은 자유입니다 — 다만 [1절 제약](#1-규격)만 지켜지면 게임에 그대로 들어갑니다.

## 1. 규격

| | 값 |
|---|---|
| **셀** | **48 × 64px** |
| **시트** | 4열 × 4행 = **192 × 256px** |
| **인물 실제 높이** | **56 ~ 62px** (2 ~ 2.5등신) |
| **발 위치** | 셀 하단에서 **2px 위** |
| **배경** | 투명 (알파 0) |
| **색 수** | 인물당 **8 ~ 12색** |
| **외곽선** | 어두운 색 **1px** |
| **파일명** | `sprite_{id}.png` |

**폭은 타일 한 칸(48px)이고 세로만 1.33칸입니다.** 정사각 48×48에 2.5등신을 넣으면 머리 19px · 몸 29px가 되어 **긴 머리가 들어갈 자리가 없습니다** — 민아·윤정은 높게 묶은 머리, 승희는 허리까지 오는 웨이브입니다. 세로 여유 16px이 그 자리입니다.

**안티에일리어싱을 넣지 마세요.** 게임이 최근접 이웃으로 확대하므로 흐린 픽셀은 그대로 커집니다.

```
타일 (x, y) 에 서 있을 때  →  스프라이트를 (x*48, y*48 − 16) 에 그림
```

## 3. 시트 배치

**한 인물이 한 장.** 4열 × 4행, 왼쪽 위부터 오른쪽으로 읽습니다.

```
        1열        2열        3열        4열
        정지       걷기1      걷기2      걷기3
1행  ┌──────────┬──────────┬──────────┬──────────┐
아래 │  ↓ 정면  │          │          │          │   48 × 64
     ├──────────┼──────────┼──────────┼──────────┤
2행  │  ← 좌향  │          │          │          │
왼쪽 ├──────────┼──────────┼──────────┼──────────┤
3행  │  → 우향  │          │          │          │
오른 ├──────────┼──────────┼──────────┼──────────┤
4행  │  ↑ 뒷모습│          │          │          │
위   └──────────┴──────────┴──────────┴──────────┘
                                        192 × 256
```

**왼쪽 행은 오른쪽 행의 좌우 반전으로 만들면 됩니다.** 그러면 두 방향이 어긋날 수 없습니다.

### 걷기 4프레임

| 열 | 자세 |
|---|---|
| 1 · 정지 | 두 발이 나란히. **멈추면 항상 이 컷** |
| 2 · 걷기1 | 왼발 앞 |
| 3 · 걷기2 | 두 발이 모임 (정지와 다르게 — 몸이 살짝 위로) |
| 4 · 걷기3 | **오른발 앞** |

재생은 `2 → 3 → 4 → 3` 순환이 아니라 **`2 → 3 → 4` 순환**입니다. 3이 두 발 모인 중간 자세라 그것만으로 자연스럽게 돕니다.

## 4. 전 인물 공통

### 명찰

**열여덟 종 전원, 전 컷 착용입니다.**

- 가슴에 밝은 **2 × 3px 사각형**
- 목에서 내려오는 **1px 검은 줄**

입소 때 받아 열이틀 내내 겁니다. 벗는 건 D7 외출과 D12 수료식뿐이고 **둘 다 도트로는 안 나옵니다.** 48px에서는 점 몇 개지만 계속 보입니다.

> **명진혁만 랜야드 색이 다릅니다** — 운영진용입니다. 참가자의 검은 줄과 구분되어야 합니다.

### 복장은 종당 한 벌

D7 사복은 반신 CG로만 나오고 **도트로는 등장하지 않습니다.** 열이틀 내내 같은 차림입니다.

### 테마 컬러를 옷에 쓰지 마세요

테마 컬러는 **UI 강조색**입니다. 머리색·옷색과 무관합니다 — 민아는 청록인데 검은 머리, 윤정은 금빛인데 갈색 머리입니다.

## 10. 검수

한 종을 끝낼 때마다:

- [ ] 셀이 정확히 **48 × 64**, 시트가 **192 × 256**인가
- [ ] 열여섯 칸이 **같은 인물**인가 — 색이 칸마다 흔들리지 않는가
- [ ] 발이 셀 하단에서 **2px 위**에 있는가 (열여섯 칸 전부 같은 높이)
- [ ] **명찰**이 열여섯 칸에 다 있는가
- [ ] 색이 **8~12개**인가
- [ ] 외곽선이 **1px**이고 끊긴 데가 없는가
- [ ] **안티에일리어싱이 없는가** — 확대해서 확인
- [ ] 배경이 완전히 투명한가 (알파 0, 흰색 아님)
- [ ] 걷기 `2 → 3 → 4` 순환이 떨지 않는가
- [ ] 왼쪽 행이 오른쪽 행의 **정확한 좌우 반전**인가
- [ ] **맵 위에 얹었을 때** 타일과 밀도가 맞는가
