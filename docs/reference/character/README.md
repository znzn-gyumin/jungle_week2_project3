## 카드에서 확정된 것

### 테마 컬러가 카드와 의상에 들어가 있습니다

| 인물 | 테마 컬러 | 카드 | 의상 |
|---|---|---|---|
| 김민아 | `#3A9B96` 청록 | ● | 검은 후드집업 |
| 이승희 | `#B5806F` 적갈 | ● | 베이지 니트 |
| 장윤정 | `#E0A230` 금빛 | ● | **노란 후드** |
| 김민규 | `#4E6288` 회청 | ● | 검은 후드 |
| 이승민 | `#5F8F42` 초록 | ● | **초록 바시티 재킷** |
| 장윤호 | `#C9A170` 크림 | ● | **크림 가디건** |

**여섯 다 카드에 들어가고, 넷은 의상에도 반영됩니다.** 민아·민규만 검은 옷이라 카드로만 드러납니다 — 둘 다 어두운 계열이라는 게 그림에서도 유지됩니다.

**머리색과 눈색은 테마 컬러와 무관합니다.** 민아는 청록인데 검은 머리, 윤정은 금빛인데 갈색 머리입니다.

### 참가자 명찰

여섯 다 **`J` 로고 목걸이형 명찰**을 걸고 있습니다. 랜야드 색은 검정 공통입니다.

**명찰은 캠퍼스 안에서 늘 걸려 있습니다.** 벗는 건 **D7 외출**과 **D12 수료식** 두 번뿐이고, 그래서 없어질 때만 눈에 띕니다 ([WORLD_BIBLE 7-3](../../WORLD_BIBLE.md#7-3-공통--참가자-명찰)). 게임 CG의 **평상복 몸통이 이 착용 상태**입니다.

### 동물 아이콘

카드 우하단에 동물상이 선화로 들어갑니다 — 고양이 · 사슴 · 강아지 · 늑대 · 공룡 · 강아지. [CHARACTERS 2-0](../../CHARACTERS.md#2-0-한눈에)의 동물상과 일치합니다.

### 대표 대사

| 인물 | |
|---|---|
| 김민아 | "…내가.. 도와주는 거니까 착각하지 마." |
| 이승희 | "…굳이 말하지 않아도 알았으면 해요." |
| 장윤정 | "선배! 이거 이렇게 하면 더 예쁠 것 같아요!" |
| 김민규 | "…필요한 말만 해." |
| 이승민 | "야, 이거 우리 팀 무조건 1등 각이다!" |
| 장윤호 | "선배! 제가 도울 수 있는 거 있으면 말해주세요!" |

여섯 다 [CHARACTERS](../../CHARACTERS.md#2-히로인-6인)의 어미 규칙을 따릅니다 — 민규는 5~15자, 윤호는 `-요`, 윤정은 `-요!`와 감탄사.

**다만 이 대사들은 호감도 0~24 구간이 아닙니다.** 카드를 첫인상 씬의 대본으로 쓰면 안 되는 이유가 둘입니다.

| | 카드 | 0~24 구간 |
|---|---|---|
| **이승민** | 반말 (`각이다!`) | `{P} 님` + 존댓말 — 반말은 25부터 |
| **장윤호** | `선배` | `선배님` — `선배`는 25부터 |
| **장윤정** | `선배` | `선배님` |

- 승민과 윤호는 **25~49 구간의 목소리**입니다
- **카드는 플레이어 이름을 모릅니다.** 그래서 `{P}`가 들어가는 호칭은 이름이 빠진 채 적혀 있습니다 — 윤정의 `선배`는 실제로는 `{P} 선배`(`도윤 선배`)입니다

**0~24 구간 대사를 쓸 때는 [CHARACTERS](../../CHARACTERS.md#2-히로인-6인)의 호칭 표를 따로 봐야 합니다.** 카드가 정본인 것은 **외형뿐**입니다.
