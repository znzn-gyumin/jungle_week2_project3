| 파일 | 내용 |
|---|---|

**카드가 정본인 것은 그림뿐입니다.** 설정값은 다른 곳에 있습니다.

| 찾는 것 | 정본 |

| 테마 컬러 · 동물상 · 외형 · 의상 · 어미 규칙 | [CHARACTERS 2절](../../CHARACTERS.md#2-히로인-6인) |

## 대표 대사

카드에 인쇄된 여섯 줄입니다.

| 인물 | |
|---|---|
| 김민아 | "…내가.. 도와주는 거니까 착각하지 마." |
| 이승희 | "…굳이 말하지 않아도 알았으면 해요." |
| 장윤정 | "선배! 이거 이렇게 하면 더 예쁠 것 같아요!" |
| 김민규 | "…필요한 말만 해." |
| 이승민 | "야, 이거 우리 팀 무조건 1등 각이다!" |
| 장윤호 | "선배! 제가 도울 수 있는 거 있으면 말해주세요!" |

### 이 대사를 첫인상 씬에 쓰면 안 됩니다

**호감도 0~24 구간의 목소리가 아닙니다.** 승민과 윤호는 **25~49 구간**으로 적혀 있습니다.

| | 카드 | 0~24 구간 |
|---|---|---|
| **이승민** | 반말 (`각이다!`) | `{P} 님` + 존댓말 — 반말은 25부터 |
| **장윤호** | `선배` | `선배님` — `선배`는 25부터 |
| **장윤정** | `선배` | `선배님` |

**카드는 플레이어 이름을 모릅니다.** 그래서 `{P}`가 들어가는 호칭이 이름 없이 적혀 있습니다 — 윤정의 `선배`는 실제로는 `{P} 선배`(`도윤 선배`)입니다.

0~24 구간 대사를 쓸 때는 [CHARACTERS](../../CHARACTERS.md#2-히로인-6인)의 호칭 표를 따로 봅니다.
