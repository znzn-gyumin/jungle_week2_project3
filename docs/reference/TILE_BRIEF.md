## 0. 범위와 한계

| | 수량 | 생성 도구로 되는가 |
|---|---|---|
| **타일셋** | 3종 | ⚠️ **분위기 시안은 뽑히지만 이어붙는 타일로는 안 나옵니다** |
| **타일맵** | 7개 | ❌ **생성 불가** — Tiled 에디터에서 타일셋으로 조립합니다 |
| 조명 | 5종 | — 그림이 아니라 **색값**입니다 (5절) |

**이어붙는 타일셋은 생성 모델로 안 나옵니다.** 격자가 어긋나고 인접 타일의 이음매가 안 맞습니다. 실제 경로는 이렇습니다.

1. 생성으로 **타일 시트**를 뽑습니다 — 1024 × 1024 정사각에 4열 × 4행쯤이면 셀당 256px
2. **[`tools/cut_sheet.py`](../../tools/cut_sheet.py)로 잘라** 48px로 줄입니다

```bash
python tools/cut_sheet.py tileset_indoor.png out/tiles --cols 4 --rows 4 --resize 48x48 --dekey ffffff
```

3. **이음매를 손으로 잡습니다.** 생성물은 인접 타일이 안 맞으므로 바닥 타일은 **4장을 실제로 붙여** 확인하고 가장자리를 다듬습니다

> **캐릭터 도트와 같은 경로입니다.** 셀을 48px로 **줄이는** 작업이라 확대와 반대로 픽셀이 선명해집니다.

## 1. 화풍 기준

**캐릭터 도트와 같은 결이어야 합니다.** 타일이 배경이고 캐릭터가 그 위에 서므로, 기준은 [`DOT_SPEC.md`](./character/DOT_SPEC.md)의 수치입니다 — 1px 외곽선, 48px 격자.

| | |
|---|---|
| 타일 | **48 × 48px**, 투명 배경 PNG, 격자에 정확히 맞을 것 |
| 시점 | **탑다운 오블리크** (쯔꾸르식 비스듬한 위에서) |
| 외곽선 | 어두운 색 **1px** |
| 색 | **제한 팔레트** — 한 타일셋 안에서 24~32색 |
| 캐릭터 | 2~2.5등신 치비가 이 위를 걸어다닙니다. **가구 높이를 캐릭터 키에 맞춰** 잡으세요 |

**게임의 정서는 조명이 만듭니다.** 타일 자체는 **낮 기준 한 벌**만 만들고, 시간대는 위에 컬러 오버레이를 얹습니다(5절). 타일을 시간대별로 여러 벌 만들지 마세요.

### 연결

```
                          M1 4F   ← 허브
                            ↕ 계단
                          M2 2F
                            ↕ 계단
  M7 정문 ──정문──        M3 1F        ──후문── M5 커넥트가든 ── M6 숙소동
                            ↕ 계단
                          M4 B1
```

**M3(1F)이 수직 동선의 허브입니다** — 위로 M2, 아래로 M4, 밖으로 M7과 M5. B1은 1F 아래라 **M3에 붙습니다**([GAME_DESIGN 6-3](../GAME_DESIGN.md#6-3-맵과-배경)).

- **교육동 3F는 만들지 않습니다.** 이번 기수가 안 쓰는 빈 층이라 계단을 **4F ↔ 2F 직결**로 처리합니다
- `portal` 오브젝트에 목적지 맵과 도착 좌표를 넣습니다

```json
{ "name": "portal", "to": "m2_basecamp_2f", "x": 320, "y": 96, "spawnX": 320, "spawnY": 640 }
```

### M1과 M5만 먼저 만들어도 게임이 돕니다

**M1이 허브, M5가 감정 정점**입니다. 이 둘 + 둘을 잇는 이동만 있으면 프롤로그부터 엔딩까지 한 바퀴가 돕니다. 나머지 5개는 그 뒤에 붙입니다.

### M5 커넥트가든 — 빼면 안 되는 둘

**이 게임 최대 명장면의 무대**라 두 가지가 반드시 있어야 합니다. 원본은 [`campus/connect_garden.jpg`](../../assets/bg/campus/outdoor/connect_garden.jpg).

**① 야외 테이블과 의자**

사진의 데크에는 **흰 와이어 프레임 의자·테이블**과 **올리브그린 의자·테이블**이 섞여 있고, 가운데에 **초록 원형 받침 하이테이블과 스툴**이 있습니다. 이게 있어야 합니다.

| 시점 | 의자 |
|---|---|
| **D1 밤** | 지나치며 흘끗 본다. 아무도 없다 |
| **D7 새벽 → 여명** | 둘이 거기 앉는다. **처음으로 채워진다** |
| **D11 새벽** | 다시 앉는다. 이번엔 곧 비게 될 걸 안다 |

> **빈 의자가 채워졌다가 다시 비는 게 이 공간의 모티프**입니다. 의자가 없으면 그 컷이 성립하지 않습니다. 벤치 하나로는 부족합니다.

**② 필로티 아래 통로**

배경 건물이 **흰 원기둥 위에 떠 있고, 그 아래로 건너편이 뚫려 보입니다.** M5는 "두 동 사이"이고 **매일 건너는 구간**이라, 통과하는 느낌이 그림에 있어야 합니다.

- 맵 한쪽 끝(숙소동 방향)에 **기둥 열과 그 아래 열린 통로**
- 통로 너머로 건너편이 보이게

> **"건너간다"가 이 게임의 작별 인사입니다** — 교육동에서 숙소동으로 간다 = 오늘은 잔다. 그 동선이 여기를 지납니다.

## 4. M1 교육장 403 — 좌석 배치 (가장 중요)

**지정석이라 누가 어디 앉는지가 그대로 캐릭터 묘사입니다.** NPC 배치가 이 도면을 따릅니다.

```
        [문 1] ──── 화이트보드 ──── [문 2]
   ┌────────────────────────────────────┐
   │                                    │
   │                          [ 연하 ]  │  앞줄 · 문2 옆
   │                                    │
   │              [ 주인공 ]             │
   │                                    │
   │         [ 4 조 · 4 명 ]            │  가운데 줄
   │                                    │
   │  [ 연상 ]                  [ 동갑 ] │  뒷줄
   │   기둥 뒤                   창가     │
   └══════════════ 창 ══════════════════┘
```

| 표기 | 인물 |
|---|---|
| **동갑** | 김민아 / 김민규 — 뒷줄 창가 |
| **연상** | 이승희 / 이승민 — 뒷줄 기둥 뒤 |
| **연하** | 장윤정 / 장윤호 — 앞줄 문2 옆 |
| **4조** | 가운데 줄에 **네 명이 나란히** — 뭉쳐 있다는 게 이 조의 표현 |

- **화이트보드가 앞, 맞은편이 통창**입니다. 앞자리일수록 문과 코치에 가깝고 뒷자리일수록 창과 바깥에 가깝습니다
- **문이 둘**입니다. 연하가 문2 옆에 앉으므로 **문1로 나가면 지나치지 않습니다** — 회피가 물리적으로 가능해야 합니다
- **기둥**이 뒷줄 한쪽에 있어야 합니다. 시선이 안 닿는 자리를 만드는 장치입니다
- **무명 17명**은 남는 자리를 공용 스프라이트로 채워 **스물네 자리가 다 찬 것처럼** 보이게만 합니다

### 자리마다 누가 앉는지가 정해져 있습니다

**균일한 그리드로 깔면 안 됩니다.** 아래 넷은 위치 자체가 의미입니다.

| 자리 | 누구 | 왜 거기인가 |
|---|---|---|
| **뒷줄 창가 끝** | **동갑** (민아 / 민규) | 화이트보드에서 가장 먼 자리. 강의를 안 들어도 아는 사람의 자리이고, **아무도 뒤에서 화면을 못 봅니다** |
| **뒷줄 기둥 옆** | **연상** (승희 / 승민) | 시선이 안 닿는 자리 |
| **앞줄 문2 옆** | **연하** (윤정 / 윤호) | 오가는 사람이 다 보이고, 드나드는 사람을 챙기기 좋은 자리 |
| **가운데 줄 한가운데 4석** | **4조** (강태윤·강태연 · 한지오·한지아 · 조민 + 무명 1) | **넷이 나란히 붙어** 있어야 합니다. 뭉쳐 있다는 것 자체가 이 조의 표현 |

**주인공은 가운데**입니다 — 학번도 실력도 가운데인 사람의 자리.

> **6조 넷이 세 방향으로 흩어져 있는 게 핵심입니다.** 누구에게든 말을 걸려면 일어나 걸어가야 하고, **어느 방향으로 걷느냐가 곧 루트 선택**입니다. 4조가 가운데 뭉쳐 있는 것과 대비됩니다.

**나머지 자리는 무명 17명**을 공용 스프라이트로 채웁니다.

### 화이트보드는 상호작용 지점입니다

**M1에 반드시 들어가야 합니다.** 인게임 낙서가 챕터마다 쌓이는 곳이고, **플레이어 방명록이 이 위에 얹힙니다.** 다가가면 읽을 수 있어야 하므로 접근 가능한 타일로 잡으세요.

## 5. 조명 오버레이 — 5종 (그림이 아닙니다)

타일맵은 **맵당 한 벌**이고, 시간대는 그 위에 오버레이를 얹어 만듭니다.

| 시간대 | 색 | 블렌드 | 불투명도 | 추가 |
|---|---|---|---|---|
| **낮** | `#FFE6B8` | soft-light | ~12% | 채도 −10% |
| **저녁** | `#E8763C` → `#2A3A63` 그라데이션 | overlay | ~35% | 창 쪽 주황, 안쪽 남색 |
| **밤** (23~01) | `#153A4A` | multiply | ~45% | 모니터 위치에 청록 발광 |
| **심야** (02~03) | `#0B1220` | multiply | **~72%** | **점광원만** 남김 |

**심야를 72%까지 깊게 두는 게 이 게임의 정체성입니다.** 캠퍼스 주변에 야산과 전원주택뿐이라 도시 불빛이 없고, 광원은 **발밑 조명 · 건물 창 · 모니터 · 자판기**뿐입니다. 얼굴이 거의 안 보이는 어둠이 기본값입니다.
