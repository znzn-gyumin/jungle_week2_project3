## 할 일 — 이미지 생성 (사람이 합니다)

**이 세션은 이미지를 만들 수 없습니다.** 팩을 이미지 생성 도구에 넣는 건 사람이 합니다.

**팩은 파일 하나가 요청 하나**입니다. 열면 그대로 복사할 게 다 들어 있습니다 — 프롬프트 · 부정 프롬프트 · 참조 이미지 경로 · 받고 나서 확인할 것.

### 순서 — 셋만 먼저

```
① B01  김민아 평상복 몸통    여러 번 뽑아 하나 확정
② F01  김민아 표정 시트      잘라서 ①에 얹어봅니다
③ S01  김민아 도트 시트      48px로 줄여 pixel_demo.png와 비교
```

**②가 갈림길입니다.** 잘라 얹었을 때 얼굴이 떨리면 시트를 버리고 몸통에서 얼굴만 인페인팅하는 쪽으로 돌아가야 하고, **요청이 36번 더 붙습니다.** 여섯을 다 만든 뒤에 알면 늦습니다.

**③이 화풍을 확정합니다.** 참조 CG가 없는 도트 12종이 전부 여기서 파생되고, **타일 세션의 화풍 판단도 여기에 걸려 있습니다.**
