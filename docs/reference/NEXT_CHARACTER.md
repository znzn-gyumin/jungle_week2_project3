### 할 일 — 도트 스프라이트를 코드로

**[`tools/tilegen/`](../../tools/tilegen/)이 이미 이 방식으로 타일셋 3종을 만들었습니다.** 같은 경로로 캐릭터 도트를 그립니다.

### 왜 생성이 아니라 코드인가

| | 생성 도구 | 코드 |
|---|---|---|
| 48px 격자 정합 | 매번 확인 | **정의상 보장** |
| 4방향이 같은 인물인가 | 흔들림 | **정의상 보장** |
| 팔레트 8~12색 | 사후 감축 | 스냅으로 강제 |
| 1px 외곽선 | 손으로 | 알파 팽창으로 기계적 |
| **타일과 화풍 일치** | 안 맞을 수 있음 | **같은 코드베이스라 자동** |
| 수정 | 다시 뽑아야 함 | 함수 한 줄 |

**타일과 같은 결로 나온다는 게 가장 큽니다.** 캐릭터가 배경 위에서 붕 뜨는 문제가 구조적으로 사라집니다.

**포기하는 것** — [`character/pixel_demo.png`](./character/pixel_demo.png) 수준의 회화적 밀도(머리카락 하이라이트, 옷 주름)는 코드로 못 따라갑니다. **형태·비율·팔레트·외곽선은 맞출 수 있습니다.**

[`ART_BRIEF.md` 0절 「파일 규격」](./character/ART_BRIEF.md#파일-규격)과 같습니다.

| | |
|---|---|
| 컷 | **48 × 48px** |
| 시트 | 4열 × 4행 = **192 × 192px**, 투명 배경 PNG |

| 열 | **정지 · 걷기1 · 걷기2 · 걷기3** |
