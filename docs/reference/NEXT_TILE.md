### ① M1 좌석 — 지정석의 의미 부여 ✅

균일 그리드를 폐기했습니다. 줄마다 책상 섬(pod)의 크기와 위치가 다릅니다.

```
              [문1 x5]        ┌── 화이트보드 x12~16 ──┐        [문2 x23]
   앞줄  y12    4   7  10     │        아일           │  19  (22)  25
   2줄   y16    4   7  10     │       (15)            │      23   26
   가운데y20    4              │  12 14 16 18 ←4조 밀착│           26
   뒷줄  y24   (5)  8  11     │                       │  21  24  (27)
              ↑기둥(3,21)
   ═════════════════════ 남쪽 통창 y27 ═════════════════════
```

| 자리 | 좌표 | 누구 |
|---|---|---|
| 뒷줄 창가 끝 | (27,24) | **동갑** 김민아 / 김민규 |
| 뒷줄 기둥 옆 | (5,24) | **연상** 이승희 / 이승민 |
| 앞줄 문2 옆 | (22,12) | **연하** 장윤정 / 장윤호 |
| 가운데 줄 한가운데 4석 | (12,20)(14,20)(16,20)(18,20) | **4조** 강태윤·강태연 / 한지오·한지아 / 조민 / 무명 1 |
| 가운데 | (15,16) | **주인공** |

- **세 방향 분산** — 주인공 기준 연하는 오른쪽 위, 연상은 왼쪽 아래, 동갑은 오른쪽 아래.
  어느 방향으로 걷느냐가 곧 루트 선택이 됩니다.
- **4조는 간격 2칸**, 다른 줄은 3칸. 뭉쳐 있는 게 눈으로 보입니다.
- **총 24석 · 무명 17명.** 1차의 25석(주인공석 별도) 해석을 접고 브리프대로 24석에 주인공을
  포함했습니다.

### ② M5 커넥트가든 — 의자와 필로티 통로 ✅

**야외 테이블과 의자** — 테이블 8세트(흰 와이어프레임 + 올리브그린 혼합) + 가운데 **초록 원형
하이테이블 2조**, 앉을 수 있는 자리 **27개**. 신규 타일 `high_table` · `stool_g/w` ·
`chair_out_left/right`.

D7·D11에 둘이 앉는 자리는 `trigger` 레이어의 **`two_chairs`**(11,14 · 4×3칸)로 잡아뒀습니다.

**필로티 아래 통로** — 맵 남쪽(숙소동 방향) 끝 y36~42.

```
   y36    건물 밑면이 시작되는 그늘 경계
   y37~41 그늘진 통로 + 흰 원기둥 5본 (x1,7,13,19,25)
   y42    그늘이 끝나는 경계
   y43~45 건너편(숙소동 앞마당) — 통로 너머로 보이는 밝은 포장
```

기둥 사이가 전부 뚫려 있어 가로로 완전히 통과됩니다. 신규 타일 `piloti_round` ·
`f_pave_shade` · `f_soffit_top/bot`. `trigger` 레이어의 **`piloti_passage`** 가 이 구간입니다.

### ③ 여명 — 보라 → 파랑 ✅

원인은 **블렌드 순서**였습니다. 밝은 낮 화면에 `screen`만 얹으면 바탕의 따뜻한 우드데크 색이
그대로 살아남아 분홍이 됩니다. "해 뜨기 직전이지 일출이 아니다"라는 브리프 문장대로 심야의
어둠이 남아 있어야 해서, **스펙의 색·블렌드는 그대로 두고 앞에 어둠을 깔았습니다.**

```
① 채도 −60%
② #171326 multiply 74%      ← 선행 어둠 (해 뜨기 직전)
③ #5B3E8C → #3E6BB0 screen 42%   ← 스펙 그대로
```

실측 결과 **위 hue 259°(보라) → 아래 225°(파랑)**. `qa.py` 가 렌더 결과의 Hue를 직접 재서
검사합니다.
