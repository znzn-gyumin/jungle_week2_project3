## 3차 작업 결과

### M4(B1) 계단 → M3(1F) ✅

`GAME_DESIGN 6-3` 정본대로 고쳤습니다. **M3이 수직 동선의 허브**가 됐습니다.

```
        M7 정문 ──정문── M3 1F ──후문── M5 커넥트가든 ──── M6 숙소동
                          │  ↕ 계단
                       M2 2F ──계단── M1 4F   ← 허브
                          │
        M3 1F ────────────┴─ ↕ 계단 ── M4 B1
```

| 계단 | 좌표 |
|---|---|
| M3 1F ↕ M2 2F | M3 (27,3) ↔ M2 (27,25) |
| M2 2F ↕ M1 4F | M2 (20,3) ↔ M1 (31,24) — 3F가 없어 4F↔2F 직결 |
| **M3 1F ↕ M4 B1** | **M3 (31,3) ↔ M4 (25,3)** ← 이번에 바꾼 것 |

- `m2_basecamp_2f` 의 `stairs_to_b1` **제거**
- `m3_basecamp_1f` 에 `stairs_to_b1` **추가** (복도 x31~32)
- `m4_basecamp_b1` 의 `stairs_to_2f` → **`stairs_to_1f` · `to: m3_basecamp_1f`**

포탈 왕복 정합·도착 좌표 통행 가능 여부는 `qa.py` 가 자동 검사합니다. 통과.

### 생성기 출력 경로 버그 ✅

`paths.py` 를 신설해 두 레이아웃을 구분합니다.

| 레이아웃 | 조건 | 출력 위치 |
|---|---|---|
| **배포** (이 저장소) | `tilegen` 의 부모 폴더 이름이 `tools` | 저장소 루트 — `assets/` `preview/` |
| 개발 (생성기만 따로) | 그 외 | `<부모>/out/assets` `<부모>/out/preview` |

환경변수 `JL_OUT` 으로 강제 지정도 됩니다. 저장소와 같은 구조를 만들어 실제로 돌려서
`assets/` `preview/` 에 쓰는 것까지 확인했습니다.

## 보류 — 화풍 밀도

타일은 외곽선이 옅은 저채도 미니멀에 27~32색이고, 캐릭터는 1px 외곽선에 8~12색입니다
([SPRITE_SPEC 1절](./character/SPRITE_SPEC.md#1-규격)). **배경이 조용하고 캐릭터가
도드라지는 건 VN·RPG에서 정상**이라 꼭 나쁜 건 아닙니다.

**판단은 캐릭터 도트를 맵 위에 얹어봐야만 가능합니다.** `S01 김민아 도트 시트`가 나오면
`preview/map_m1_basecamp_4f.jpg` 위에 합성해 보고 결정합니다. **그때까지 타일은 건드리지 않습니다.**

합성할 때 볼 것:

1. 캐릭터가 배경에서 **읽히는가** — 안 읽히면 배경 대비를 낮추지 말고 캐릭터 외곽선을 살립니다
2. **가구 높이** — 책상 상판이 캐릭터 허리쯤인가 (현재 책상 앞면 14px 기준)
3. **색 충돌** — 캐릭터 대표색(`#1E1E24` `#6A67C5` `#E3B15A`)이 카펫·벽과 붙어 보이지 않는가
