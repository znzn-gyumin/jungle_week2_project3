# 타일셋 · 타일맵 — 수정 요청

`assets/` 산출물을 [`TILE_BRIEF.md`](./TILE_BRIEF.md)와 대조한 결과입니다. **먼저 알아둘 것: 만들어진 것의 품질은 높습니다.**

- 타일셋 3종이 48px 격자에 정확히 맞고 이음매가 없습니다
- 팔레트가 27·28·32색으로 실측 관리됩니다
- 조명 5종이 실제로 돌아가고 **심야가 충분히 어둡습니다** — 볼라드 점광원만 남는 게 스펙대로입니다
- 맵 7개 + `lighting.ts` + 재빌드 가능한 생성기까지 브리프보다 많이 나왔습니다

**"생성 → 컷 → 손보정" 대신 코드로 직접 그린 판단도 타당합니다.** 격자 정합과 이음매를 정의상 보장하는 쪽이 맞습니다. `tools/cut_sheet.py`를 남겨둔 것도 좋습니다.

아래 셋만 고쳐 주세요. **①②는 브리프가 얇게 쓰여 있던 탓이라 브리프도 함께 보강했습니다.**

## ① M1 좌석 — 지정석의 의미가 없습니다 (제일 중요)

현재 `m1_basecamp_4f.json`은 **균일한 4행 × 2블록 그리드**에 NPC 26개가 골고루 놓여 있습니다.

**맵 형태는 이미 맞습니다** — 문 둘이 화이트보드 쪽, 창이 하단, 기둥이 좌하단. **NPC 좌표만 재배치**하면 됩니다.

[`TILE_BRIEF 4절`](./TILE_BRIEF.md#자리마다-누가-앉는지가-정해져-있습니다)에 배정표를 새로 넣었습니다.

| 자리 | 누구 |
|---|---|
| **뒷줄(창가 쪽) 창가 끝** | **동갑** — 김민아 / 김민규 |
| **뒷줄 기둥 옆** | **연상** — 이승희 / 이승민 |
| **앞줄(화이트보드 쪽) 문2 옆** | **연하** — 장윤정 / 장윤호 |
| **가운데 줄 한가운데 4석 — 나란히 붙여서** | **4조** — 강태윤·강태연 · 한지오·한지아 · 조민 + 무명 1 |
| 가운데 | 주인공 |
| 나머지 | 무명 17명 (공용 스프라이트) |

**왜 이게 중요한가** — 6조 넷이 **세 방향으로 흩어져** 있어야 "누구에게든 말을 걸려면 일어나 걸어가야 하고, **어느 방향으로 걷느냐가 곧 루트 선택**"이라는 설계가 성립합니다. 4조가 가운데 뭉쳐 있는 것과의 대비도 여기서 나옵니다.

기둥은 **뒷줄 한쪽**에 있어야 하고(시선이 안 닿는 자리를 만드는 장치), 문이 둘인 것도 **마주치기 싫으면 문1로 나갈 수 있게** 하려는 겁니다.

## ② M5 커넥트가든 — 야외 의자와 필로티 통로가 없습니다

우드데크 · 석축 화단 · 어린 나무(지지대 포함) · 볼라드 조명은 잘 옮겨졌습니다. 둘이 빠졌습니다.

[`TILE_BRIEF 3절`](./TILE_BRIEF.md#m5-커넥트가든--빼면-안-되는-둘)에 절을 새로 넣었습니다.

**야외 테이블과 의자** — 원본 [`campus/connect_garden.jpg`](./campus/connect_garden.jpg)에는 **흰 와이어 프레임 의자·테이블**과 **올리브그린 의자·테이블**이 섞여 있고 가운데에 **초록 원형 하이테이블과 스툴**이 있습니다. 현재 맵에는 벤치 하나 정도뿐입니다.

> **빈 의자가 채워졌다가 다시 비는 게 이 공간의 모티프입니다.** D1에 지나치며 흘끗 보고 → D7에 둘이 앉고 → D11에 다시 앉는데 이번엔 곧 빌 걸 압니다. **의자가 없으면 이 게임 최대 명장면의 그림이 성립하지 않습니다.**

**필로티 아래 통로** — 배경 건물이 흰 원기둥 위에 떠 있고 그 아래로 건너편이 뚫려 보입니다. M5는 "두 동 사이"이고 매일 건너는 구간이라, 맵 한쪽 끝(숙소동 방향)에 **기둥 열과 그 아래 열린 통로**가 필요합니다.

> **"건너간다"가 이 게임의 작별 인사입니다** — 교육동에서 숙소동으로 간다 = 오늘은 잔다. 그 동선이 여기를 지납니다.

## ③ 여명 색이 스펙과 다릅니다

`preview/lighting_m5_connect_garden.jpg`의 여명이 **따뜻한 분홍** 쪽입니다. 스펙은 **보라 → 파랑**입니다.

```
#5B3E8C  →  #3E6BB0   screen  ~40%
```

**게임 전체에서 딱 한 번 쓰는 색**이고 타이틀 로고(먹빛 + 보라 발광)와 같은 계열이라, 여기가 어긋나면 시그니처가 흐려집니다. 해 뜨기 **직전**이지 일출이 아닙니다.

## 확인만 필요한 것 — 화풍 밀도

인수인계 9절에서 스스로 flag한 항목입니다. 판단을 보류합니다.

타일은 외곽선이 옅고 저채도 미니멀인데 `pixel_demo.png` 캐릭터는 굵은 1px 외곽선에 만화적입니다. **다만 이게 꼭 나쁜 건 아닙니다** — 배경이 조용하고 캐릭터가 도드라지는 건 VN·RPG에서 정상이고 가독성에 유리합니다.

**실제 판단은 캐릭터 도트를 맵 위에 얹어봐야만 가능합니다.** 병렬로 도는 캐릭터 세션에서 `S01 김민아 도트 시트`가 나오면 M1 위에 합성해 보고 그때 결정합니다. **지금은 타일을 건드리지 마세요.**
