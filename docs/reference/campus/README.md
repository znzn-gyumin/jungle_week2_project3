## 커넥트가든 — `connect_garden.jpg` 확정

사이트에 "커넥트가든"이라는 이름으로 올라온 사진은 없지만, **"카페 앞 테라스"가 실제로 그 공간**입니다.

- 앞: 카페 앞 우드데크 + 야외 테이블·의자
- 중: 석축 화단, 심어진 나무들, 계단
- 뒤: **필로티(기둥) 아래로 건너편이 뚫려 보임** — 교육동에서 숙소동으로 건너가는 통로
- 상단 오렌지 요소가 `edu_terrace.jpg`의 중정 난간과 동일 → 같은 건물 권역 확인

**세 씬(D1 · D7 · D11) 전부 이 한 장의 시간대 변형**으로 커버합니다 ([WORLD_BIBLE 4-3](../../WORLD_BIBLE.md#4-3-커넥트가든--이-게임의-중심-공간)).

> 정확히는 커넥트가든 전체가 아니라 **카페에 면한 데크 구역**입니다. 게임에서 쓰는 지점을 여기로 고정하면 D1 "지나가는 길" 묘사도 데크 옆을 지나는 것으로 쓰면 자연스럽습니다.
