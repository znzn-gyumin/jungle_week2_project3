## 1. 전체 플로우

```
로그인 (Google · 필수)
 └ 타이틀
    ├ 이어하기  → 세이브 3슬롯 + 오토세이브 (계정에 저장)
    ├ 방명록    → 교육장 403 화이트보드 · 진행 일자까지의 글이 보임
    └ 새 게임   → 성별 선택 (남/여) → **이름 입력** (성 1~2자 + 이름 1~3자)
        └ 프롤로그  : D1  (월)     — 입소, 조·숙소 배정, 첫 인사 → **밤에 루트 확정**
           └ 과정 1 : D2~D3 (화·수)  — 짝 프로그래밍. 확정된 루트의 첫 밀착
              └ 과정 2 : D4~D6 (목~토) — 랭킹 공개, 미니 프로젝트 밤샘, 소나기
                 └ 과정 3 : D7  (일)     — 유일한 휴일. 외출 (장소 3택)
                    └ 과정 4 : D8~D11 (월~목) — 파이널 프로젝트, 마무리
                       └ 결말 : D12 (금) 수료식 → 5년 후 에필로그
                          └ **화이트보드가 지워지는 컷 → 방명록 쓰기 개방**
```

**11박 12일 = D1~D12**이고, 8월 첫째 주 월요일에 시작해 둘째 주 금요일에 끝납니다. 플레이 단위는 날짜가 아니라 **6개 챕터**입니다.

### 1-1. 챕터별 구조 (공통 템플릿)

각 챕터는 동일한 리듬으로 반복됩니다.

1. **도입 내레이션** (챕터 상황 제시)
2. **캠퍼스 이동** — 도트 맵을 걸어 다음 이벤트 지점까지 감. *(3개 챕터에서만)* **경로를 벗어나 돌아다니며 말을 걸 수 있음**
3. **메인 이벤트 씬** — 히로인과의 대화, 선택지 1~3개
4. **호감도 판정 + 마무리 내레이션**

시스템 구현은 한 번만 하면 되고 이후는 스크립트 교체입니다.

### 1-2. 캠퍼스 안 = 도트 이동 / 캠퍼스 밖 = 이벤트 씬

**표현 방식이 장소로 갈립니다.** 이 대비가 D7 외출의 무게를 화면으로 만듭니다.

| | 캠퍼스 안 | 캠퍼스 밖 (D7 외출) |
|---|---|---|
| 이동 | **도트 맵 자유 이동** (7개 맵) | 없음 |
| 화면 | 타일맵 + 도트 캐릭터 + 대사창 | **일러스트 배경** + 대사창 |
| 진행 | 걸어가서 말을 걸거나, 지점에 도달하면 이벤트 발동 | 씬이 순서대로 재생 |

**열이틀 내내 도트로 걸어다니다가 D7 하루만 화면이 통째로 바뀝니다.** 유일한 휴일이라는 설정을 대사로 설명할 필요가 없어집니다.

#### 이동은 자유, 대화는 제한

이동을 열어도 **"오늘 말 걸 수 있는 횟수"는 그대로 제한**합니다. 자원 관리는 이동이 아니라 상호작용에 걸립니다.

| 챕터 | 자유 이동 | 대화 횟수 | 비고 |
|---|---|---|---|
| 프롤로그 (D1) | ◆ | **2회** | 히로인 3인 중 2명만. 사실상의 루트 선택 |
| 과정 1 (D3) | — | — | **짝 프로그래밍은 고정 씬.** 상대가 자동 결정이라 선택이 없음 |
| 과정 2 (D5 밤) | ◆ | **2회** | 밤샘 중. 히로인 3인 / 명진혁 중 |
| 과정 3 (D7) | — | — | 캠퍼스 밖이라 해당 없음 |
| 과정 4 (D8) | ◆ | **2회** | 팀 빌딩. 히로인 3인 / 4조 정찰 중 |
| 과정 4 후반·결말 | — | 0회 | 클라이맥스는 이벤트로만 진행 |

**캠퍼스 안이면 언제나 도트로 걷습니다.** 다만 **경로를 벗어나 돌아다닐 수 있는 구간은 셋뿐**입니다 — D1 · D5 · D8 ([SCENARIO_OUTLINE](./SCENARIO_OUTLINE.md)의 ◆ 표시와 일치).

| | 이동 | 들를 수 있는가 |
|---|---|---|
| **자유 이동 구간** (D1 · D5 · D8) | 자유 | **어디든** — 히로인·화이트보드 |
| 나머지 캠퍼스 안 챕터 | **다음 이벤트 지점까지 정해진 경로** | 없음 |
| 캠퍼스 밖 (D7) | 없음 | — |

**방명록을 자유 이동 구간에서만 쓸 수 있는 이유가 여기 있습니다** ([2-5](#2-5-계정과-방명록)) — 화이트보드에 다가가려면 경로를 벗어날 수 있어야 합니다.

**이동을 열면 "찾아가는 행위" 자체가 선택이 됩니다.** 셋이 늘 같은 자리에 있는 게 아니라 **그날 상태에 따라 다른 곳에 있습니다.** 누구를 만날지 정하려면 어디 있을지 짐작하고 찾아가야 합니다 — 민아 / 민규는 언제나 자기 지정석, 승희 / 승민은 사람을 피해 2층이나 라운지, 윤정 / 윤호는 작업 모드일 때만 2층. **찾는 행위 자체가 그 인물을 이해했다는 증거**가 됩니다 ([WORLD_BIBLE 4-2-1](./WORLD_BIBLE.md#4-2-1-24시간-공간이-둘이라는-것)).

## 2. 시스템

### 2-1. 호감도

- 범위 0~100, 시작 10
- **1회차 선택지 11개** — 일반 6 + **루트 확정 1**(P-1) + 트레이드오프 4. 여기에 자유 이동 중 대화가 더해집니다
  - 정답 `+7` / 무난 `+3` / 오답 `-3` / 루트 확정 `+6` / 자유 이동에서 히로인과 대화 `+6`
  - **P-1은 정답이 없습니다.** 누구를 고르든 그 사람의 루트가 열리므로 `+6` 고정입니다 ([SCENARIO_OUTLINE 7절](./SCENARIO_OUTLINE.md#7-선택지-총람))
- **UI에 수치를 직접 노출하지 않음.** 대신 챕터 종료 시 히로인의 한 줄 반응으로 간접 표시합니다. **문장이 인물마다 다릅니다** — 같은 호감도라도 말투가 달라야 게이지가 아니라 사람으로 읽힙니다. 인물별 반응 문장은 [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 각 인물 절에 있습니다
- **반응 3구간과 호칭 4구간의 대응은 이렇습니다.** 반응 문장은 그 구간의 **호칭·어미 규칙을 따라야** 합니다

| 반응 | 호감도 | 호칭 구간 |
|---|---|---|
| **낮음** | 0~24 | 0~24 |
| **중간** | 25~79 | 25~49 · 50~79 |
| **높음** | **80~** | 80~ |

  **`높음`은 80 구간이므로 반말이 시작된 뒤입니다** — 이승희·장윤정·장윤호는 여기서 처음 반말을 씁니다 ([2-4](#2-4-호칭-시스템))
- 힌트는 절친(한지오/한지아)이 대사로 제공 — 공략 가이드 역할

### 2-2. 실력 (v1.0)

- 범위 0~100, 시작 0
- 호감도와 **트레이드오프**되는 선택지 **4개** (과정 2에 둘, 과정 3·4에 하나씩)
  - 호감도 측: `호감도 +7`
  - 실력 측: `실력 +25` / `호감도 -2`
  - 예) D6 새벽 2시 — "같이 야식 먹으러 간다" vs "구현 마저 끝낸다"
- 최종 발표(과정 4)와 5년 후 에필로그의 커리어 묘사에 반영
- **핵심 설계 의도**: 연애만 챙기면 엔딩에서 본인 커리어가 비어 있고, 실력만 챙기면 혼자 성공한다. True 엔딩은 양쪽 다 일정선 이상일 것을 요구

> **티켓이 조 단위라 실력 스탯에 서사적 근거가 생깁니다.** 1등 조 전원이 티켓을 받으므로, 주인공의 실력이 낮으면 **히로인까지 티켓을 놓칩니다.** True 엔딩이 실력 50 이상을 요구하는 이유가 수치가 아니라 이야기로 설명됩니다 ([WORLD_BIBLE 5-1-2](./WORLD_BIBLE.md#5-1-2-티켓이-조-단위라는-것)).

#### 수치 검산

**전제**: 시작 `10` + 일반 선택지 6개 전부 정답(`+7` × 6 = `+42`) + 루트 확정 P-1(`+6`) + **자유 이동에서 루트 히로인과 3회 대화**(`+6` × 3 = `+18`) = **`76`**. 자유 이동은 세 구간이고 **이미 만난 상대는 다시 못 고르므로**, 한 구간에서 루트 히로인을 만날 수 있는 건 1회씩입니다.

| 플레이 방식 | 호감도 | 실력 | 엔딩 |
|---|---|---|---|
| 트레이드오프 4회 전부 호감도 | 100 (상한) | 0 | **Good** — 연인이지만 커리어가 빈 엔딩 |
| 4회 전부 실력 | 68 | 100 | **Good** — 각자 잘 사는 엔딩 |
| **2:2로 배분** | 86 | 50 | **True** |
| 오답을 섞은 플레이 | ~45 | ~25 | **Normal** |

양쪽 극단이 전부 Good에 떨어지고 **가운데를 잡아야 True**가 나옵니다. 어느 한쪽만 밀면 안 된다는 게 이 게임의 주제이므로, 수치가 그걸 강제합니다.

### 2-3. 엔딩 판정

| 조건 | 엔딩 |
|---|---|
| 호감도 ≥ 80 **and** 실력 ≥ 50 | **True** |
| 호감도 ≥ 80, 실력 < 50 | **Good** (연인이지만 커리어 묘사가 흐림) |
| 호감도 50~79 | **Good** |
| 호감도 < 50 | **Normal** (동기로 남음) |

**루트는 프롤로그 D1 밤 선택지(P-1)에서 확정됩니다.** 그때 아무도 고르지 않으면 **솔로 엔딩** 1종으로 처리합니다.

### 2-4. 호칭 시스템

호감도 수치를 UI에 노출하지 않는 대신, **히로인이 주인공을 부르는 호칭이 관계 게이지 역할**을 합니다. 대학생 배경이라 학번 차이가 있고, 한국 대학 문화에서 호칭 변화는 그 자체로 관계의 사건입니다.

**여섯이 각자 다릅니다.** 학번 관계가 다르고 성격이 다르므로 출발점도 도착점도 갈립니다. **여자 히로인은 남주인공(이도윤)을, 남자 히로인은 여주인공(이도아)을 부릅니다.**

**4단계 대응표는 [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 각 인물 절에 있습니다.** 여기서는 시스템 규칙만 정의합니다.

**표에 적힌 `도윤` · `도아`는 기본 이름입니다.** 플레이어가 이름을 바꾸면 함께 바뀌고, **호격조사(`도윤아`)와 접미사(`도윤이`)가 붙는 자리는 받침 유무로 자동 판정**됩니다 ([TECH_DESIGN 3-2](./TECH_DESIGN.md#3-2-치환-토큰)).

#### 구간이 실제로 언제 넘어가는가

[2-2 검산](#2-2-실력-v10)의 정답 플레이 기준입니다. **집필 시 그 씬에서 어느 호칭을 쓸지가 여기서 결정**됩니다.

| 구간 | 넘는 지점 | 그때까지의 씬 |
|---|---|---|
| **25** | C1-1 · D3 짝 프로그래밍 | 프롤로그 전부 |
| **50** | ★C2-2 · D6 새벽 밤샘 | 코드리뷰 · 랭킹 · D5 자유 이동 · 조 충돌 |
| **80** | ★C3-3 · **D7 귀소 버스** | 커넥트가든 명장면 · 외출 |

**커넥트가든 최대 명장면(D7 새벽)이 50 구간에서 벌어집니다.** 아직 반말도 안 나오고 호칭도 도착점이 아닙니다 — 그래서 **귀소 버스에서 호칭이 한 단계 바뀌는 것**이 그날 하루의 결산이 됩니다 ([WORLD_BIBLE 4-4](./WORLD_BIBLE.md#귀소-버스)).

**80 구간은 D7 밤부터**라 실제로는 마지막 나흘뿐입니다. 이승희·장윤정·장윤호의 첫 반말, 김민아·김민규의 `{P:호격}`, 이승민의 `우리 {P}`가 전부 여기 몰립니다.

| 호감도 구간 | 0~24 | 25~49 | 50~79 | 80~ |
|---|---|---|---|---|
| 성격 | 첫 호칭 | 이름을 부르기 시작 | 거리가 줄어듦 | **관계가 바뀐 표지** |

**쓸 수 있는 조각은 아래가 전부입니다.** 인물별 표는 이것들의 조합입니다.

| 조각 | 뜻 | 기본 이름 대입 |
|---|---|---|
| `{P}` | 이름 | 도윤 / 도아 |
| `{P:성명}` | 성 + 이름 | 이도윤 / 이도아 |
| `{P:호격}` | 이름 + 호격조사 — **부를 때** | 도윤아 / 도아야 |
| `{P:접미}` | 이름 + 접미사 `-이` — **뒤에 관계어가 올 때** | 도윤이 / 도아 |
| `{P} 님` `{P} 선배` | 이름 + **공적** 관계어 | 도윤 님 · 도아 선배 |
| `{P:접미} 오빠` `{P:접미} 누나` | 이름 + **사적** 관계어 | 도윤이 오빠 · 도아 누나 |
| `선배님` `선배` `야` | 이름 없는 호칭 | — |
| *(빈 문자열)* | 안 부름 | — |

- **출발점과 도착점이 인물마다 다릅니다.** 김민규는 0~24가 빈 문자열이고, 이승민은 25에서 이미 반말이며, 장윤호는 80에서 `선배`를 놓고 `누나`로 넘어갑니다
- **80 구간의 도착점이 세 갈래로 갈립니다.**

| 도착점 | 인물 | 뜻 |
|---|---|---|
| **`{P:호격}`** — 도윤아 · 도아야 | 김민아 · 이승희 · 김민규 | 이름을 부르는 것 자체가 도착점 |
| **관계어** — 도윤이 오빠 · 도아 누나 | 장윤정 · 장윤호 | 나이 차가 거리가 아니라 애정 표현이 됨 |
| **`우리 {P}`** — 우리 도아 | 이승민 | 챙기는 사람의 소유격 |

- **연하 둘이 `오빠` / `누나`로 대칭이되 도착 시점이 다릅니다** — 장윤정은 50 구간, 장윤호는 80 구간. 위계 차이가 속도 차이로 나타납니다
- **호칭이 안 움직이는 구간은 다른 축이 받습니다.** 이승민은 25 이후 **에코백**이, 장윤정은 80에서 **어미가 반말로 풀리는 것**이 게이지를 대신합니다
- **첫 반말 시점도 게이지입니다.** 동갑 둘은 처음부터, 이승민은 25, **이승희·장윤정·장윤호는 80** — 셋이 같은 지점에 도착하되 이유가 각자 다릅니다(부끄럼 · 애교 어미 · 위계)
- **접미사는 사적 호칭에만 붙습니다** — `도윤이 오빠`는 되고 `도윤이 선배`는 안 됩니다. 그래서 `선배` → `오빠/누나` 전환이 **관계어와 이름 형태를 함께 바꿉니다** ([TECH_DESIGN 3-2](./TECH_DESIGN.md#3-2-치환-토큰))
- **주인공이 히로인을 부르는 호칭(`{H:호칭}`)은 넷이 고정, 둘만 움직입니다.** 동갑(민아·민규)과 연하(윤정·윤호)는 처음부터 이름이라 바뀔 게 없고, **연상인 이승희·이승민만 3단계**를 갑니다. 단계별 값은 [CHARACTERS](./CHARACTERS.md#2-히로인-6인)의 해당 인물 절에 있습니다
- **움직이는 둘은 전환 자체가 선택지로 등장합니다** ("이제 그냥 이름으로 불러도 될까요?"). 이승민이 `형`이 아니라 `오빠`인 것은 **남자 히로인이라 여주인공만 만나기 때문**입니다.
- 호칭이 바뀌는 순간은 반드시 **한 줄 내레이션으로 짚어줍니다.** 플레이어가 진전을 체감하는 유일한 피드백이므로 그냥 흘려보내면 안 됩니다
- 구현상으로는 `{P:호칭}` 토큰이 현재 호감도 구간과 루트를 보고 치환됩니다 ([TECH_DESIGN 3-2](./TECH_DESIGN.md#3-2-치환-토큰))

##### 인게임 날짜가 해금 조건입니다

**자기 진행이 그 날짜에 닿아야 그 날짜의 글이 보입니다.**

**화이트보드는 도트 맵(M1)에 있으므로 자유 이동 구간에만 다가갈 수 있습니다** ([1-2](#1-2-캠퍼스-안--도트-이동--캠퍼스-밖--이벤트-씬)). 그래서 글에 찍히는 날짜는 **네 개**입니다.

| 쓸 수 있는 시점 | `inGameDay` |

| 프롤로그 자유 이동 | **D1** |

| 과정 4 팀 빌딩 자유 이동 | **D8** |
| 수료식 직후 | **D12** |

| 내 진행 | 보이는 글 |
|---|---|
| D1 | D1에 쓴 글만 |
| D5 | D1 · D5 |
| D8 | D1 · D5 · D8 |

**챕터마다 한 층씩 쌓입니다.** 인게임 낙서가 D1에 깨끗하다 점점 차오르는 것과 같은 곡선이고, **네 챕터가 곧 네 단계**가 됩니다. D1에는 거의 비어 있고 진행할수록 남의 글이 늘어납니다 — 초반의 허전함은 연출상 오히려 맞습니다.

##### D12에 두 층이 교차합니다

| | 인게임 낙서 | 방명록 |
|---|---|---|
| 쓰는 주체 | 게임 — 챕터 진행에 따라 늘어남 | 실제 플레이어 |
| **D12 수료식** | **지워짐** (연출) | **전부 열림** |
| 새 회차 · 게임 중 | 다시 D1부터 쌓임 | 그 회차 진행 일자까지만 |

**D12가 이 기능의 정점입니다.** 열이틀치 인게임 낙서가 지워진 자리에, **네 챕터에 걸쳐 쌓인 진짜 사람들의 글이 한꺼번에 드러납니다.** 게임이 비운 자리를 사람이 채우고 있었다는 게 그때 보입니다.

- 방명록 글은 **영구 보존**입니다. 회차를 반복하거나 세이브를 지워도 남습니다
- **게임 중에는 그 회차의 진행 일자까지**만 보이지만, **타이틀에서는 계정의 최고 도달 일자 기준**이라 한 번 D12에 닿았으면 언제든 전부 볼 수 있습니다. 회차를 새로 시작해도 봤던 게 사라지지 않습니다
- 방명록에 필요한 새 에셋은 **없습니다** — 화이트보드 배경은 M1 타일맵에 이미 있고, 글은 그 위에 얹습니다
- **씬이 아니라 UI**라 [7절 분량 예산](#7-분량-예산)의 90씬에 들어가지 않습니다

## 4. 과정 3 — 주말 외출 3택

**12일 중 유일하게 쉬는 날(D7 일요일)**입니다. 합숙 규정상 외박 불가 · 23시 귀소라 딱 하루뿐이고, 그래서 시간이 아깝습니다. 돌아가는 **시내버스**에서의 대화가 이 챕터의 진짜 클라이맥스입니다.

셋 다 캠퍼스에서 버스로 닿는 **용인권**이고 대학생 예산입니다.

각 장소마다 **전용 배경 1장**이 있고, **여섯이 각자 선호 하나 · 무난 하나 · 비선호 하나**를 갖고, **한 장소를 선호하는 인물이 정확히 둘씩**입니다. 어느 장소를 골라도 누군가에게는 정답입니다. 장소별 근거는 [WORLD_BIBLE 4-4](./WORLD_BIBLE.md#4-4-외출-3곳-d7).

| 인물 | 에버랜드 | 한국민속촌 | 명지대 대학가 |
|---|---|---|---|
| **김민아** | `+1` | `+3` | **`+7`** |
| **김민규** | `+1` | `+3` | **`+7`** |
| **이승희** | `+3` | **`+7`** | `+1` |
| **이승민** | **`+7`** | `+3` | `+1` |
| **장윤정** | **`+7`** | `+1` | `+3` |
| **장윤호** | `+1` | **`+7`** | `+3` |

**나이대가 같은 짝 중 선호가 겹치는 건 민아·민규(동갑)뿐**입니다. 연상 둘(승희 민속촌 / 승민 에버랜드)과 연하 둘(윤정 에버랜드 / 윤호 민속촌)은 서로 엇갈립니다.

**장소를 공유하는 짝은 조를 가로질러 생깁니다** — 민속촌은 승희·윤호, 에버랜드는 승민·윤정입니다. 서로 다른 조라 한 회차에 같이 나오지 않으므로 게임 안에서는 겹침으로 보이지 않고, **승희·윤호는 이유까지 반대**입니다. 인물별 근거는 [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 각 인물 절에 있습니다.

- 비선호 장소를 고르면 `+1`에 그치지만 **패널티는 없음** — 대신 "왜 여기를 골랐는지" 후속 선택지가 열려 만회 가능
- 장소는 히로인이 묻고 **주인공이 고릅니다.** 상대가 뭘 좋아할지 아는지를 시험하는 선택지입니다
- 이 챕터는 유일하게 캠퍼스 밖이라 **도트 이동이 없고 일러스트 배경으로만** 진행됩니다 ([1-2](#1-2-캠퍼스-안--도트-이동--캠퍼스-밖--이벤트-씬))
- **귀소 버스 씬은 3장소 공통**입니다. 배경 1장(야간 시내버스)으로 세 갈래를 다 받아내므로 비용 대비 효율이 가장 좋은 씬입니다. 고백 직전까지 가는 대사와 **호칭 전환**을 여기에 배치

## 5. 결말 — 5년 후 (18종)

**6인 × 3티어.** 여섯이 각자 다른 서브플롯을 가지므로 엔딩도 공유하지 않습니다.

**5년 후 = 주인공 27세.** 졸업하고 2~3년차 개발자입니다. 대학생이 시작점이라 엔딩은 "커리어의 완성"이 아니라 **"학생이던 우리가 사회인이 된 첫 구간"**의 온도로 씁니다. 결혼·성공 같은 결말보다, 그때의 열이틀이 지금의 나를 어디로 데려왔는지가 핵심입니다.

| 티어 | 판정 | 온도 |
|---|---|---|
| **True** | 호감 80+ **and** 실력 50+ | 관계도 커리어도 이어짐 |
| **Good** | 호감 80+ 실력 미달, 또는 호감 50~79 | 한쪽만 이어짐 |
| **Normal** | 호감 50 미만 | 동기로 남음 |
| **솔로** | 루트 미확정 | 5년 뒤 기수 모임에 다녀온 밤. 다들 변했고 나도 변했다 |

> 절감 팁: 조연 5명(명진혁 · 조민 · 강태윤 · 강태연 · 여사님)은 걷기를 빼고 **정지 1프레임 × 4방향 = 4컷**으로 낮춰도 티가 거의 안 납니다. → **288컷 → 228컷**

### 6-2. 이벤트 CG (히로인 전용)

**히로인 CG는 사용자가 직접 제공합니다.** 아래는 게임에 들어가는 CG의 사양입니다.

> **[확정 프로필](./reference/character/README.md)은 여기 물량에 포함되지 않습니다.** 상반신 카드라 게임용 CG가 아니라 **외형·의상·화풍의 기준**입니다. 아래 CG는 그 기준을 따라 새로 그립니다.

- 몸통(포즈): 히로인당 2종 (평상복 / D7 외출복) → **12장**
  - **평상복은 [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 `외형` 행이 정본**입니다 — 여섯 다 겉옷을 하나씩 걸치고 있습니다
  - **D7 외출복도 [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 `D7 외출복` 행이 정본**입니다. 여섯 다 **평상복보다 확실히 꾸민 차림**이고, 각자 **하루만 달라지는 지점**을 하나씩 갖습니다
  - **확정 프로필은 가슴 위 카드**라 하의가 없습니다. **하의·신발은 여섯이 다 다르고** [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 `하의·신발` 행이 정본입니다
- 표정 파츠: **6종** (기본 / 기쁨 / 부끄러움 / 슬픔 / 놀람 / **화남**) × 6명 → **36장**
- 스틸 CG(전체 삽화): 히로인당 3장 (**D7 새벽 커넥트가든(여명) / D9 클라이맥스 / 엔딩**) → **18장**

**세 장이 [6-3](#6-3-맵과-배경)의 히로인별 명장면과 정확히 일치합니다.** D12 수료식은 공통이라 히로인 스틸이 아닙니다.

**스틸별 배경 근거**

| 스틸 | 장소 · 시각 | 레퍼런스 | 팔레트 |
|---|---|---|---|
| ① D7 커넥트가든 | 카페 앞 데크 · 02시 → 여명 | [`connect_garden.jpg`](./reference/campus/connect_garden.jpg) | 심야 → **여명**(보라→파랑) |
| ② D9 클라이맥스 | 교육장 403 · 심야 | [`classroom_1.jpg`](./reference/campus/classroom_1.jpg) · [`classroom_2.jpg`](./reference/campus/classroom_2.jpg) | 심야(먹빛 남색 · 점광원) |
| ③ 엔딩 | 5년 후 · 캠퍼스 아님 | **없음** — 오피스 / 전시장 / 밤 창가 ([6-3](#6-3-맵과-배경) 배경 5~7) | — |

팔레트는 [WORLD_BIBLE 8-1](./WORLD_BIBLE.md#8-1-시간대별-팔레트). 승희·승민의 ①은 4F 라운지에서 시작해 가든으로 내려오는 씬이라 [`community_lounge_1.jpg`](./reference/campus/community_lounge_1.jpg)를 보조 참고로 쓸 수 있습니다.

**D7 외출에는 스틸을 두지 않습니다.** 장소가 셋이라 스틸로 처리하면 6인 × 3장소 = **18장이 더** 필요해집니다. 대신 **외출복 몸통 + 일러스트 배경 3장**([6-3](#6-3-맵과-배경))으로 받습니다 — 몸통 2종 중 하나가 이 날을 위해 있는 이유입니다 ([WORLD_BIBLE 4-4](./WORLD_BIBLE.md#4-4-외출-3곳-d7)).

**레이어 방식을 전제로 합니다** — 몸통과 표정을 분리해야 2 × 6 = 12 조합이 나옵니다. 통짜로 그리면 인당 12장이 되어 물량이 두 배입니다. **평상복과 외출복은 얼굴 위치·크기가 같아야** 표정 파츠 6장을 두 몸통에 공용으로 씁니다.

**크롭은 가슴 위 반신**입니다. 전신이 아니라 흉상이라 얼굴이 크게 보이고, 표정 6종을 쓰는 설계와 맞습니다. **하의·신발은 CG에 안 나오고 도트와 스틸에서만 보입니다** — 설정은 [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)의 `하의·신발` 행에 그대로 살아 있습니다.

**명찰은 몸통에 그려 넣습니다** — 평상복은 걸고 있고 외출복은 없습니다. 벗는 때가 D7 외출과 D12 수료식 둘뿐이라 별도 파츠가 필요 없습니다 ([WORLD_BIBLE 7-3](./WORLD_BIBLE.md#7-3-공통--참가자-명찰)).

> **`화남`은 지금 시나리오에서 김민아 초반에만 쓰입니다.** 그래도 6종에 넣어 받아둡니다 — 나중에 시나리오를 고치거나 더 맞는 표정이 필요할 때 다시 의뢰하지 않아도 됩니다.

## 7. 분량 예산

### 7-1. 1회차 예산 (목표 20~30분)

기준: 한 줄 ≈ 25자, 타자 효과 + 클릭 진행으로 **분당 약 15줄** (≈375자/분). 도트 이동은 **최단 경로 기준** 챕터당 40~60초.

| 챕터 | 대사 줄 | 도트 이동 | 선택지 | 소요 |
|---|---|---|---|---|
| 프롤로그 (D1 월) | 77 | 90초 (M7→M3→M4→M1→M5→M6) | 1 | 6.6분 |
| 과정 1 (D2~D3 화·수) | 50 | 40초 | 2 | 4.0분 |
| 과정 2 (D4~D6 목~토) | 85 | 60초 | 3 | 6.7분 |
| 과정 3 (D7 일) | 50 | 20초 (M3 출발까지만) | 3 | 3.7분 |
| 과정 4 (D8~D11 월~목) | 60 | 50초 | 2 | 4.8분 |
| 결말 (D12 금 + 5년 후) | 35 | 30초 | 0 | 2.8분 |
| **합계** | **357줄** | **약 4.8분** | **11개** | **≈29분** |

**목표 20~30분 범위 안입니다.** 이동 시간은 **최단 경로 기준**이고, 탐색을 즐기는 플레이어는 더 걸립니다 — 그건 보너스로 두고 예산에 넣지 않습니다.

프롤로그가 가장 긴 이유는 대사 분량 때문만이 아니라 **입소 동선이 캠퍼스를 한 바퀴 돌기 때문**입니다. 정문 → 로비 → 정글스테이지 → 교육장 403 → 커넥트가든 → 숙소동 순서로 **7개 맵 중 6개에 첫날 들르면서 공간을 익히게** 됩니다. 나머지 하나(M2 교육동 2층)는 계단으로 지나칠 뿐이라, **D5 자유 이동에서 처음 목적지가 됩니다** — 승희 / 승민을 찾으려면 내려가야 하는 층입니다.

**프롤로그와 과정 2가 가장 깁니다.** 프롤로그는 3인 중 둘을 만나 첫인상을 남기고 루트까지 고르게 해야 하므로 구조적으로 길 수밖에 없고, 과정 2는 밤샘·소나기·커넥트가든이 몰린 감정적 정점입니다. 과정 1과 4는 각각 "어색함"과 "마무리"라는 단일 기능이라 50줄이면 충분합니다.

#### 6인분이라 물량이 큽니다

남녀 대사를 공유할 수 없으므로 6루트를 각각 씁니다 ([CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)). 다만 **커지는 건 전체 완성 물량뿐**입니다.

| | 값 |
|---|---|
| 1회차 플레이 분량 | **357줄 + 이동 · 약 29분** |
| MVP (히로인 1인 완주) | **27씬 · 477줄** |
| 씬 구성표 | **1벌.** 씬 자리·비트·선택지 위치는 여섯이 공통 |
| 전체 완성 | **90씬 / 1,980줄** |

**기획 문서는 6벌이 되지 않습니다.** 씬의 "기능"이 여섯 공통이라 [SCENARIO_OUTLINE](./SCENARIO_OUTLINE.md)은 한 벌로 유지되고, 갈라지는 건 `.vns` 대사뿐입니다. 파일은 `routes/minah.vns` … `routes/yunho.vns` 여섯으로 나뉩니다.

#### 무엇이 갈리고 무엇이 안 갈리는가

| 층위 | 6루트 공통 | 6인 각자 |
|---|---|---|
| 12일 달력 · 6챕터 | ● | |

| 공통 씬 18개 (212줄) | ● | |
| **각 씬에서 일어나는 사건** | | ● |
| 서브플롯 | | ● |
| 선택지 텍스트와 정답 | | ● |
| 모티프 | | ● |
| 대사 · 에셋 | | ● |

**뼈대만 공유하고 살은 전부 다릅니다.** 씬 자리는 여섯 루트가 똑같지만, 그 칸에서 무슨 일이 벌어지는지는 여섯 명이 각자 다릅니다.

이 방침의 비용은 **재활용이 안 된다는 것**입니다. 나이대가 같은 남녀끼리도 사건이 달라 "한쪽 쓰고 고쳐 쓰기"가 성립하지 않습니다. 줄 수(1,980줄)는 그대로지만 **집필 난이도가 올라가고 구성표가 인물 6벌로 유지**됩니다.

#### 여섯이 재활용되지 않는 이유

공유되는 건 **"각자 자기 방식으로 무너지고, 주인공이 그걸 목격한다"**는 골격 한 줄뿐입니다. 실력 1위 둘조차 **민아는 "들키는" 이야기, 민규는 "태우는" 이야기**이고, 최고학번 둘도 승희는 "말하지 못하는" 이야기, 승민은 "너무 많이 하는" 이야기입니다. **여섯 개가 서로 다른 결핍을 다룹니다** ([CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)).

> 씬 자리는 여섯이 똑같으므로 [SCENARIO_OUTLINE](./SCENARIO_OUTLINE.md)의 **골격 표는 한 벌**로 유지하고, 각 씬의 내용만 6열로 적습니다.

- 1회차 노출량(357줄)이 전체의 1/5인 이유는 **루트 6개와 데이트 장소 3개가 배타적**이기 때문입니다

### 7-3. 집필 규칙

대사 357줄은 넉넉하지 않습니다. 아래 규칙으로 밀도를 지킵니다.

1. **씬 하나에 비트 하나.** 쓰기 전에 "이 씬이 하는 일"을 한 문장으로 적고, 끝나면 즉시 씬을 닫습니다
2. **인사와 잡담을 삭제.** 씬을 대화 중간부터 시작합니다
3. **모티프와 호칭에 일을 시킵니다.** 얼음이 녹은 아메리카노 한 줄이 관계 설명 다섯 줄을 대신합니다. [WORLD_BIBLE 7절](./WORLD_BIBLE.md#7-반복-모티프) · [CHARACTERS 2절](./CHARACTERS.md#2-히로인-6인)
4. **내레이션으로 시간을 건너뜁니다.** 다만 씬이 없는 날은 D2·D10 이틀뿐이라 여지가 적습니다 ([SCENARIO_OUTLINE](./SCENARIO_OUTLINE.md))

## 8. 제작 순서

### MVP — 세로 슬라이스 1개

1. **Google 로그인 + Firestore 세이브** — 배포·도메인과 함께 **가장 먼저** 뚫습니다 ([TECH_DESIGN 7](./TECH_DESIGN.md#7-구현-순서))
2. 시스템: 대사 표시, 선택지, 호감도 변수, 씬 전환
3. **도트 맵 2개** — M1(교육장 403) · M5(커넥트가든) + 둘을 잇는 이동
4. 주인공(남) 1명 + **여자 히로인 3인**(민아 · 승희 · 윤정) — 루트는 **장윤정 하나만**이고 나머지 둘은 첫인상과 조원 대사만 씁니다. 랭킹 공개와 조 충돌 씬이 셋을 다 요구합니다
5. **장윤정 루트만** 프롤로그~엔딩까지 완주 (True/Good/Normal 3종)

이 시점에서 이미 **플레이 가능한 완결 게임**이며 포트폴리오로 제출할 수 있습니다.

> MVP 분량은 **27씬 / 약 480줄**입니다 — 공통 **15씬 182줄**(프롤로그 5 · **첫인상 3** · 공용 7) + 장윤정 루트 9씬 235줄 + 엔딩 3씬 60줄.
>
> **첫인상이 3씬인 이유**는 주인공이 남자라 남자 히로인 셋이 아예 등장하지 않기 때문입니다. 인물을 추가할 때마다 **12씬 / 295줄**씩 붙고, 여주 플레이를 열 때 남자 첫인상 **3씬 30줄**이 한 번 더 붙습니다.
>
> **1회차 재생량은 357줄입니다.** 첫인상 씬은 6개인데 한 회차에 재생되는 건 둘뿐이라, 나머지 넷은 집필 총량에만 잡힙니다.
>
> **맵 2개로 시작하는 이유**: 프롤로그가 원래 6개 맵을 지나가지만, MVP에서는 나머지를 이벤트 씬으로 대체하고 M1·M5만 실제 이동으로 만듭니다. 이동 시스템이 도는지 검증하는 데는 두 개면 충분합니다.
