# 화면 폰트

**`junglover.woff2` 하나만 여기 넣으면 켜집니다.** `src/boot.css` 의 `@font-face` 가
이 폴더를 보고 있고, Vite 가 번들하며 경로와 해시를 붙입니다 — 개발 서버와
GitHub Pages 양쪽에서 그대로 돕니다.

| 형식 | 넣을까 |
|---|---|
| **`.woff2`** | **넣으세요.** 모든 현대 브라우저가 읽고 가장 작습니다 |
| `.woff` | 선택. 아주 오래된 브라우저용 대비 — 같이 넣으면 `junglover.woff` 로 |
| `.eot` | **넣지 마세요.** 인터넷 익스플로러 전용이고 IE 는 2022 년에 끝났습니다 |
| `.ttf` / `.otf` | 웹용이 아닙니다. 용량이 두세 배 큽니다 |

이름을 `junglover.woff2` 로 바꿔 넣는 게 제일 간단합니다. 다른 이름을 쓰시려면
`src/boot.css` 의 `url()` 두 줄을 그 이름으로 고치면 됩니다.

**파일이 없어도 게임은 돕니다** — `@font-face` 가 무시되고 `DungGeunMo` ·
`Pretendard` 순으로 물러납니다 ([WORLD_BIBLE 11](../../docs/WORLD_BIBLE.md#11-ui-톤)).

> 라이선스는 직접 확인해 주세요. 배포되는 저장소에 폰트 파일이 함께 올라갑니다.
